# Southern Machinery 知识卡片模板与填写规范

## 13 章节标准结构

每个产品知识卡片必须包含以下 13 个章节，缺失字段标注"待确认"。

### 1. 产品标题
格式：`{产品中文名} {型号} · {一句话定位}`
示例：`自动径向插件机 S-70LD · 高效径向元件自动插装`

### 2. 一句话定义
1-2 句话回答"这是什么设备、解决什么问题、用于什么工艺"。
要求：技术导向，避免营销空话。

### 3. 产品分类
- 类别：{SMT / THT / Wave Soldering / Board Handling / Peripheral / Accessory / Spare Part}
- 型号：{型号}
- 所属产线环节：{SMT / THT / 波峰焊 / 板处理 / 周边配套}

### 4. 适用场景
3-5 个具体场景，每条以动词开头。
示例：
- 中大批量径向元件插装
- 消费电子 PCB 板 THT 工序
- 替代人工插装提升节拍

### 5. 核心功能
3-5 条，每条用加粗功能名 + 描述。
示例：
1. **自动径向插装**：支持径向引线元件（电容、电阻、二极管）高速插装
2. **自动换线**：快速切换产品型号，减少停机时间

### 6. 关键参数
表格形式，列：参数项 / 数值 / 单位 / 备注。
缺失参数填"待确认"。
常见参数维度见下方"参数维度参考"。

### 7. 客户价值
2-4 条，从客户视角描述能获得什么。
示例：
- 人工节省：替代 X 人工
- 良率提升：插装良率 ≥ 99.X%
- 节拍提升：UPH 提升 X 倍

### 8. 适配客户类型
2-3 类客户，每类说明为什么适配。
示例：
- 消费电子代工厂：大批量、稳定节拍
- 工业控制板制造商：多品种、中批量

### 9. 常见问题 FAQ
3-5 条，Q/A 形式。
优先覆盖：选型、兼容性、维护、产能、对比。
见 `faq-patterns.md` 的句式模板。

### 10. 选型建议
- 适合：{什么客户/工艺/产量}
- 不适合：{什么场景}
- 替代/升级型号：{型号}

### 11. 关联设备
- 上游：{设备}
- 下游：{设备}
- 配套：{设备}

### 12. 可用于官网 / GEO 的关键词
- 核心词：{1-2 个}
- 长尾词：{3-5 个}
- 应用词：{2-3 个}
见 `seo-keyword-bank.md` 的关键词矩阵。

### 13. 可用于销售跟进的简短话术
- 一句话卖点：{1 句}
- 痛点话术：{针对某痛点的 1 句}
- 对比话术：{与某方案的对比 1 句}

## 参数维度参考（按产品类别）

### SMT 贴片机
PCB 尺寸（最小/最大）、元件范围（最小/最大）、贴装精度、贴装速度（CPH）、供料器数量、吸嘴数量、换线时间、电源、气源、外形尺寸、重量。

### THT 插件机
组件类型、插装方式、插装速度（UPH/每小时插装数）、适用 PCB 尺寸、组件剪切方式、换线时间、电源、气源、外形尺寸、重量。

### 波峰焊
温区数量、预热区长度、波峰类型（单波/双波）、波峰宽度、适用 PCB 宽度、传输速度、锡缸容量、电源、外形尺寸、重量。

### Board Handling
PCB 尺寸范围、上/下板方式、缓存容量、传输方向、ESD 保护、传输速度、接口尺寸、电源、外形尺寸。

### 配件（Feeder/Nozzle）
兼容主机型号、兼容品牌、元件规格、供料方式、维护周期、包装规格。

## 填写规范

1. **不编造参数**：缺失字段一律写"待确认"。
2. **单位统一**：长度 mm、重量 kg、速度 UPH/CPH、温度 ℃、电压 V、气压 MPa。
3. **型号统一**：与官方规格书完全一致，含连字符（如 S-70LD 非 S70LD）。
4. **术语统一**：中英文术语对齐，首次出现给出中英对照。
5. **矛盾标注**：多份资料参数不一致时，列出所有来源与数值，标注"以官方最新规格书为准"。
