# Southern Machinery 整线配置矩阵

> SMT → THT → 波峰焊 → 板处理的产线衔接参考，用于整线方案输出与"关联设备"章节填写。

## 标准整线流程

### 纯 SMT 产线
```
[Loader] → [锡膏印刷机] → [SMT 贴片机] → [Reflow Oven] → [AOI] → [Unloader]
                ↑                      ↑
        [锡膏搅拌机]            [钢网清洗机]
                               [吸嘴清洗机]
```

### 纯 THT 产线
```
[Loader] → [THT 自动插件机] → [波峰焊] → [PCBA Cleaning] → [Unloader]
                ↑
        [径向/轴向/异形 Feeder]
```

### SMT + THT 混合产线（最常见）
```
[Loader] → [锡膏印刷] → [SMT 贴片] → [Reflow] → [AOI]
   → [Buffer] → [THT 插件] → [波峰焊] → [PCBA 清洗] → [Unloader]
```

### 双面 PCB 产线
```
[A 面] Loader → 印刷 → SMT → Reflow → AOI
   → [Flipper/Inverter 翻板]
[B 面] → 印刷 → SMT → Reflow → AOI → Unloader
```

## 设备衔接接口标准

| 接口类型 | 标准 | 说明 |
|---------|------|------|
| 机械接口 | SMEMA | 标准传送带高度、宽度 |
| 信号接口 | SMEMA | 板到位信号、上下游握手 |
| 轨道宽度 | 可调 | 根据 PCB 宽度调整 |
| 传输方向 | 左→右（默认） | 可定制右→左 |

## 产线节拍匹配原则

整线产能由**最慢工位**决定。配置原则：
1. 主机（贴片机/插件机/波峰焊）为节拍基准。
2. 上下游 Board Handling 设备速度 ≥ 主机速度的 1.2 倍。
3. Buffer 缓存机用于平衡上下游节拍差异，避免堵塞。
4. Loader/Unloader 容量 ≥ 1 小时产量的料架数。

## 按产量级别的配置建议

| 产量级别 | SMT 配置 | THT 配置 | Board Handling |
|---------|---------|---------|---------------|
| 小批量（<5K/天） | 单台多功能贴片机 | 1 台异形插件 + 选择性焊接 | 基础 Loader/Unloader |
| 中批量（5K-30K/天） | 1 高速 + 1 多功能 | 1-2 台自动插件 + 波峰焊 | Loader + Buffer + Unloader |
| 大批量（>30K/天） | 双高速贴片机 | 多台插件机并联 + 双波峰焊 | 全自动 Loader/Unloader + 多 Buffer |

## 按行业应用的产线模板

### 消费电子（手机/家电）
- 特点：大批量、单一品种、节拍优先
- 配置：双高速 SMT + 在线 AOI + THT 自动插件 + 氮气波峰焊

### 工业控制（PLC/驱动器）
- 特点：中批量、多品种、可靠性优先
- 配置：多功能 SMT + 异形插件 + 选择性波峰焊 + 三防涂覆

### 汽车电子（ECU/传感器）
- 特点：高可靠性、追溯性、温区控制
- 配置：高精度 SMT + 氮气回流 + THT 插件 + 氮气波峰焊 + 全检 AOI

### LED 照明
- 特点：大批量、长板、铝基板
- 配置：长板专用 SMT + 长板 Reflow + 长板 Board Handling

### 医疗设备
- 特点：小批量、高可靠性、可追溯
- 配置：多功能 SMT + 选择性焊接 + 全检 AOI + X-Ray

## 整线卖点（销售话术）

1. **单一供应商**：SMT → THT → 波峰焊 → 板处理全由 Southern Machinery 提供，整线责任清晰，避免多供应商扯皮。
2. **深圳制造**：成本效益，快速交付，定制能力强。
3. **全球服务**：安装培训、备件供应、远程支持覆盖全球客户。
4. **整线节拍优化**：根据客户产品匹配产线节拍，避免瓶颈。
5. **交钥匙方案**：从工艺设计到设备安装到量产调试一站式服务。
