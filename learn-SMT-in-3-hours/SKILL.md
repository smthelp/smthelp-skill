# Learn SMT in 3 Hours

Build a practical learning package that helps a learner understand an SMT automated line as one coordinated system: board movement, material deposition, component placement, soldering, inspection, buffering, and controlled handoff. Teach verified facts as facts, label reasoned explanations as inferences, and keep unknown machine-specific details as `待确认`.

## Start With Evidence

Use the current Southern Machinery profile, model-specific manual/specification, product-folder document, or approved drawing first. Use photos and video only for visible category, configuration, or process position. Use industry material for general concepts only; it cannot prove a Southern Machinery model's capability.

Classify every diagram and machine card visibly:

| Label | Meaning |
| --- | --- |
| `已验证资料` | Directly supported by the supplied current source. |
| `概念示意` | Generic teaching view; it does not depict a particular model or configuration. |
| `待确认` | Needs the current manual, process engineer, or manufacturer confirmation. |

Never turn a filename, image, old copy, generic article, or competitor material into a model, capacity, dimensional, compatibility, certification, temperature-profile, yield, or maintenance-interval claim.

## Choose The Learning Package

Default to the full 180-minute route when the learner has not selected a topic. Tailor the route only after obtaining the next useful input: learner level, production context, a current source, and the requested emphasis. Ask at most one targeted question at a time; do not block a general overview when no source is available.

Read [the curriculum](references/curriculum.md) for the time-boxed route. Read [the visual language](references/visual-language.md) before making diagrams or visual briefs. Read [process and operations](references/process-and-operations.md) for equipment and handoff explanations. Read [troubleshooting and maintenance](references/troubleshooting-and-maintenance.md) for fault and maintenance requests.

## Produce The Learning Package

Deliver the following in the learner's language. Use Simplified Chinese for Chinese requests.

1. A one-screen line overview and learning objective.
2. A 180-minute study map with completion checks.
3. Equipment cards covering applicable board handling, printing, inspection, placement, soldering, inspection, buffering/unloading, and supporting peripherals.
4. At least six useful diagrams selected from process flow, equipment structure, material/control flow, parameter causality, fault tree, maintenance card, and coordination swimlane.
5. Parameter and operation guidance that gives parameter categories, effect, risk, verification method, and the source or `待确认` state. Do not fabricate settings.
6. A fault-to-check sequence, maintenance record, and final line-coordination recap.

Use Markdown tables for comparison and Mermaid for flow, causality, and swimlane diagrams when diagrams must remain editable. For a source-grounded visual image, first create a visual brief containing the exact source, visible features, intended labels, and the applicable evidence label. Use a `概念示意` when no suitable source image is available.

## Safety And Scope

This skill is for learning, briefing, and source-grounded guidance. It is not authorization to operate, service, defeat interlocks, bypass guards, change recipes, or perform energized work. For an abnormal condition, make the machine safe under the site procedure, follow the current manufacturer manual, and escalate to qualified personnel when the cause is not confirmed.

Equipment classes are not a promise that every line includes every station. Present optional stations as optional and show the documented line configuration where one is provided. For a Southern Machinery recommendation, recommend the equipment class first; select an exact model only from verified current material.

## Final Review

Before handing off a package, confirm:

- The study route totals 180 minutes and covers the learner's stated focus.
- Every graphic has a purpose and an evidence label.
- Specific values, model facts, and service actions have a current source or are marked `待确认`.
- The process map distinguishes required, optional, and unverified stations.
- The troubleshooting section starts with safe state and escalation boundaries.
