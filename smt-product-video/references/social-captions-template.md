# Social captions template

Deliver English LinkedIn, Facebook, and X drafts with the video (or on request), ready to post. All facts come from the verified SEO description — never introduce a new number here.

## LinkedIn (long form)

```
<Hook line — the pain point in one sentence.>

<What the product is, 2–3 sentences.>

<Specs in one line: variants, key sizes, codes/prices as listed.>

<How it is used, one line. What it does for an EMS line, one line.>

🎥 Watch: [YouTube link]
🔗 Product page: <VERIFIED landing page URL>

#<tag> #<tag> #<tag>
```

## Facebook (short form)

```
<Hook line.>

<One or two sentences: what it is + the main benefit.>

🎥 Watch: [YouTube link]
🔗 <VERIFIED landing page URL>
```

## X (≤280 characters)

```
<Hook + product + benefit in one or two sentences.>

🎥 [YouTube link]
🔗 <VERIFIED landing page URL>
#<tag> #<tag>
```

## Placeholder rules

- Before the video is published, the YouTube link is the literal placeholder `[YouTube link]`. Replace it with the real URL after upload — never guess a URL.
- The posts can go out the same day without the video: delete the `Watch` line and keep only the product-page link.
- Attach the 1280×720 thumbnail as the post image.
- After publishing, update this file with the real YouTube URL and re-deliver it.
