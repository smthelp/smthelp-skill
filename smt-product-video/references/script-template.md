# Script template

## Structure (8 beats, 190–230 words for 75–90 s)

| Beat | Time (90 s video) | Purpose |
|---|---|---|
| 1 Hook | 0:00–0:11 | The pain point, in the buyer's own terms (line stops, rethreading takes minutes) |
| 2 Reveal | 0:11–0:23 | Product name + one-line promise |
| 3 Mechanism | 0:23–0:34 | How it works, in plain steps |
| 4 Specs | 0:34–0:45 | Variants, sizes, codes, prices — only as listed on the product page |
| 5 Tool / accessory | 0:45–0:57 | Matching tool, sizes, how it fits |
| 6 How to use | 0:57–1:08 | The method, step by step, with the safety note |
| 7 Benefits | 1:08–1:19 | What it does for an EMS line (uptime, changeover, quality) |
| 8 Closing | 1:19–1:30 | Recap + CTA: Visit smthelp.com / Contact Southern Machinery |

Scale the word count proportionally for other lengths (~2.5 words per second).

## TTS rules

- Write every number as spelled-out English words: "zero point zero one five", "twelve point seven", "forty-two by thirty-six millimetres", "eight to twenty-five dollars a roll".
- Model codes are spoken digit by digit where the voiceover needs them ("SCT 031000, 030500, 051000, 050500").
- Short sentences; one idea per subtitle cue. No abbreviations the TTS would misread (write "millimetres", not "mm").
- Keep the register plain and technical — EMS engineers and plant managers. No hype adjectives, no invented superlatives.

## Facts discipline

- Every number in the script must trace to the landing page or a named source. Quote the page's own numbers.
- When sources disagree, publish the range and say so in the script if it matters (e.g. "four thousand to twelve thousand CPH").
- Efficiency or savings claims carry their source in the description (not necessarily in the voiceover): "per the product page".
- Anything unverified goes in the script only as a hedged statement, or is left out and listed as `待确认 / to be confirmed` in the delivery report.

## Subtitles

- `subtitles.srt`: ≤2 lines per entry, ≤42 characters per line, time-aligned to the voiceover (measure the real voiceover duration first; do not trust the script's estimated length).
- Convert to ASS for burn-in (see `templates/subtitles.ass`): the SRT is the deliverable for YouTube's own caption upload; the ASS is the burn-in source.
- One subtitle cue per spoken sentence or clause — never let a cue span two script beats.
