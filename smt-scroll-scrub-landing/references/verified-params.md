## 已核实的通用口径

- 供料节拍：`0.8 s/件`（STF1003 / SBF1001 / BF-2002D 实测值）
- 产能：`4,000 CPH`（S-7900）、`12,000 CPH`（S-7020T）、`10,000–12,000 CPH`（S-3000 实测）
- 精度：`±0.05 mm`（S-7900）、`±0.015 mm`（S-7020T）、`±0.5 mm`（供料器）

## ⚠️ 明确未核实（页面上必须写 `待确认`）

- S-WS450 **链速（m/min）** — 涉及节拍计算时不得自行推导
- S-7900 / S-7020T 的**适用板尺寸、换线时间、功率、气源要求**
- 所有机型的**价格、交期、认证状态、质保条款**
- 任何 **ROI / 良率提升 / 回本周期** 数字（除非有可核对的客户数据）

## 常见参数错配（出现即拦下）

| 错误 | 正确 |
| --- | --- |
| "S-70LD 支持 0.4 mm pitch BGA" | S-70LD 是插件机，不适用贴片精度指标 |
| "S-70LD 0.8 s/点" | `0.8 s/件` 是 STF1003 供料器的节拍，不是 S-70LD 的 |
| "S-WS450 产能 X 片/小时" | 缺链速，先标 `待确认` 再问工程 |
