# Smart-SMT Style Guide

## Core Personality

Smart-SMT visuals should feel like a practical future: clean automation, clear machine logic, precise motion, and confident engineering. The style should be instantly understandable to an EMS factory buyer.

The desired impression:

- "This company understands PCB assembly."
- "The solution is modern but practical."
- "The message is simple enough to understand in three seconds."

## Reference Influence

If using the `ian-xiaohei-illustrations` repository as inspiration, borrow only high-level qualities:

- Simple visual storytelling
- Friendly proportions
- Bold simplified shapes
- Clear scene reading
- Minimal visual clutter

Do not copy specific characters, poses, compositions, linework, or mascots. Smart-SMT should become Southern Machinery's own industrial B2B visual system.

## Visual Rules

Use:

- Clean machines with simplified geometry
- PCB panels, soldering paths, nozzles, feeders, conveyors, insertion heads, AOI cameras
- Futuristic factory lighting without dark sci-fi drama
- Isometric, 3/4 view, or clean front-view compositions
- Controlled negative space for captions or thumbnails
- Crisp edges and polished bitmap output

Avoid:

- Crowded comic strips
- Mascot-centered scenes
- Dark neon cyberpunk
- Excessive reflections
- Overly realistic factories with visual noise
- Fake screens filled with unreadable text
- Unverified badges such as "CE certified" or "24h delivery"

## Palette

Default palette:

- Deep machinery blue: `#0B3A75`
- Industrial graphite: `#1F2933`
- Clean white: `#F7FAFC`
- Cyan signal: `#17B7FF`
- PCB green accent: `#20A66A`
- Warning accent, sparingly: `#F6B33D`

Do not let the design become one-note blue. Use white space, graphite, cyan, and small green PCB details to keep it crisp.

## Composition Templates

### Machine Hero

One machine or machine module dominates the center. PCB panels move through it. One or two tiny simplified operators can provide scale.

Best for:

- Landing page hero
- Product category visual
- Proposal cover

### Process Line

A left-to-right SMT/THT line with 4-6 simplified stations. Use arrows, PCB traces, or light paths to show flow.

Best for:

- Complete line proposal
- Blog hero
- LinkedIn education post

### Problem To Automation

Split composition: manual bottleneck simplified on one side, automated line on the other. Keep it clean and non-judgmental.

Best for:

- Labor-saving campaign
- ROI discussion
- Outreach visuals

### Precision Close-Up

Close-up of nozzle, insertion head, AOI camera, soldering wave, or LED placement. Use macro composition with minimal context.

Best for:

- YouTube thumbnail
- Technical post
- Product feature visual

## Typography In Images

Prefer no text inside the image unless the user explicitly needs a thumbnail or ad headline.

When text is required:

- Use 2-5 words only
- Use exact English text supplied by the user or generated in the response
- Avoid tiny labels
- Avoid paragraphs
- Keep text in a clean empty area

Good examples:

- "SMT + THT Automation"
- "Line-Ready PCB Assembly"
- "Reduce Manual Handling"
- "High-Mix EMS Upgrade"

## Quality Checklist

Before accepting an image:

- Is the message clear at thumbnail size?
- Is there one dominant focal point?
- Does it look like SMT/THT automation, not generic technology?
- Are there no fake claims or fake badges?
- Is the style modern but not childish?
- Does it feel like Southern Machinery rather than a copied reference comic?
