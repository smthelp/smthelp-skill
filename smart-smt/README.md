# Smart-SMT Skill

Smart-SMT is a reusable Codex skill for Southern Machinery English marketing copy paired with image-generation prompts.

It is designed for:

- LinkedIn visual concepts
- YouTube thumbnail prompts
- Landing page hero prompts
- Blog hero illustrations
- Proposal cover visuals
- English captions for SMT/THT export marketing

The style target is concise, direct, high-tech, futuristic, and credible for global EMS factory buyers.
