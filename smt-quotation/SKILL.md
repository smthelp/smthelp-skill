# SMT Quotation - one format for every Southern Machinery quotation

```
old .xlsx/.xls --extract_quote.py--> quote.json (draft) --rewrite--> quote.json --make_quote.py--> XLSX (+PDF) --qa_quote.py--> Jason
new inquiry ------------------------> quote.json (from examples/_template) ----^
```
One quotation = one folder with `quote.json` + `photos/` + `out/`. Seller data lives once in `assets/profile.json`.

## Files
- `assets/profile.json` - company name, address, tel, contact block, sales people, **bank details (TO_CONFIRM until Jason fills them)**, colours/font, quote-number rule, default terms, term order and labels, supplier terms to block.
- `assets/sm-logo.png` - logo (from smt-brand-kit). `assets/SM-Quotation-Template.xlsx` - blank rendered template for manual use.
- `scripts/make_quote.py` - quote.json -> XLSX (A4 portrait, fit to width, page breaks between blocks, footer with contact block and Page x of y). `--pdf` exports PDF with LibreOffice (`SOFFICE=` path if not on PATH).
- `scripts/qa_quote.py` - gate. `qa_quote.py quote.json --xlsx out.xlsx` for new quotes; `qa_quote.py --legacy old.xlsx` to review any old file directly.
- `scripts/extract_quote.py` - legacy importer: header labels, item table, spec lines, options, packing line, Remark terms, detail sheets, photos.
- `references/checklist.md` - human review checklist (A brand, B terms, C consistency, D known slips). `references/terms-library.md` - approved English wording.
- `examples/` - Levven (summary + 2 detail sheets, options, photos), Visam (single sheet, photos), MRO (single, original terms kept to show QA flags), `_template`.

## Workflow
1. **Start**: new quote -> copy `examples/_template/quote.json` into `quotes/<QUOTE_NO>/`; old quote -> `python3 scripts/extract_quote.py <old file> -o quotes/<QUOTE_NO>`.
2. **Fill / rewrite quote.json** (schema in make_quote.py docstring):
   - quote_no = 2 letters (customer/country) + YYMMDD + 2-digit seq; `date` fixed ISO date; `valid_days` 30.
   - buyer: company, address, country, attn, email (address only), tel.
   - items: SM model (one spelling everywhere), plain product name, qty, unit, price, specs ("Label: value unit"), options (`included: false` = listed, not summed), `sheet` to move specs/options to a detail sheet (items may share a sheet), photo path.
   - charges: packing, freight, etc. `discount` positive number.
   - terms: only what differs from profile defaults; wording from terms-library.md. Never invent price, lead time, warranty or stock - ask Jason when the source does not say.
3. **Render**: `python3 scripts/make_quote.py quotes/<NO>/quote.json --pdf`.
4. **Gate**: `python3 scripts/qa_quote.py quotes/<NO>/quote.json --xlsx quotes/<NO>/out/*.xlsx` -> 0 ERROR; read every WARN. Look at the PDF pages.
5. **Deliver to Jason** (never to the customer): XLSX + PDF + the WARN list in Chinese (severity, location, current text, suggested fix), plus open questions in one line.
6. **Learn**: each remark from Jason -> fix the rule where it lives (profile.json default, SLIPS in qa_quote.py, terms-library.md, checklist.md, renderer), re-render the examples, bump version, add one history line, push.

## Fixed rules
- Registered name `Shenzhen Southern Machinery Sales and Service Co., Ltd.` everywhere; contact block smthelp.com · info@smthelp.com · WhatsApp +86 136 0256 2576; logo never stretched or recoloured.
- No =NOW()/TODAY(); every amount is a live formula (qty x price, subtotal, total); amount in words is regenerated by the script.
- Price basis always "<Incoterm> <named place> (Incoterms® 2020)"; payment split = 100 %; delivery and warranty each have a start point; installation says remote or on-site and who pays travel.
- Supplier names, logos, contacts and supplier model codes never appear (add them to profile.supplier_terms per product).
- Quotation is the one document where price, lead time, payment and warranty belong (smt-brand-kit's never-publish list is for marketing material).
- Bank details come only from profile.json confirmed by Jason; footer notice that bank details never change by email.

## Upgrading
- Seller/brand change -> profile.json only. New term -> profile `terms_order` + `terms_labels` + defaults. New check -> qa_quote.py (+ checklist.md). Layout change -> make_quote.py, re-render all examples and look at the PDFs.
- Version: major = quote.json format change; minor = new field/check/output; patch = fixes. Sync with GitHub smthelp/smthelp-skill.
