## 二、邮件序列设计原则（4封冷启动序列）

### 序列节奏
```
Day 0    → Cold Email（痛点 + ROI，CTA：预约15分钟会议）
Day 3-5  → Follow-up 1（客户案例，增强可信度）
Day 7-10 → Follow-up 2（新动态：展会/产品/数据）
Day 14-30→ Breakup 邮件（给价值后退场，留门）
```

### 核心规则
- **每封邮件只突出一个核心价值点**
- **绝不复制粘贴公司介绍**
- **标题必须个性化**（客户公司名或产品名）
- **CTA 清晰但不逼迫**（"Would a 15-minute call this week work?"）
- **签名包含完整联系方式**
- **中文邮件可更亲切，英文邮件保持专业紧凑**

## 三、FABE + COSTAR 邮件框架

### FABE 法则（卖点展开）
```
F (Feature)     → 设备有什么特性
A (Advantage)   → 这个特性意味着什么（比对手强在哪）
B (Benefit)     → 对客户有什么实际好处（省钱/提效/提良率）
E (Evidence)    → 具体数据或客户案例佐证
```

### COSTAR 模型（邮件结构）
```
C (Context)     → 说你理解客户的处境
O (Objective)   → 说你想帮他达成什么
S (Style)       → 解决方案导向，非推销
T (Tone)        → 专业、利他、像真人
A (Audience)    → 针对客户角色（CEO/工程经理/采购）
R (Response)    → 明确但低压力的 CTA
```
