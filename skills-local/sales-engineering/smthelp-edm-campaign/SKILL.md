# Southern Machinery EDM Campaign System

**适用场景**：为 Southern Machinery（南方机械）的 SMT/THT 自动化整线设备开拓全球 EMS/ODM/OEM 客户。

**定位**：将 ColdOutboundSkills 的28-skill体系（GrowthEngineX）落地为 SMT 设备外贸专项工具，结合 Southern Machinery 全产品线知识库，生成高转化率邮件序列。

**核心优势**：
- 极致性价比（替代日系 Fuji/Yamaha/Panasonic，节省 30-50% CapEx）
- 整线方案（SMT → THT → 波峰焊 → AGV）
- 欧盟 CE 认证

## 一、ICP（Ideal Customer Profile）定义

### 1.1 核心目标客户画像

触发此 Skill 时，先确定客户类型（可多选）：

| 客户类型 | 特征 | 推荐产品方向 |
|---------|------|------------|
| **EMS 代工厂** | 小批量多品种，计件收费，人工成本敏感 | S-70LD + S3000/S4000 |
| **ODM 厂** | NPI 频繁，换线时间要求高，柔性生产 | S-7900 + 波峰焊线 |
| **汽车电子** | 可靠性要求高（IPC-610/IATF 16949），长期验证 | S-7900 Active Clinching |
| **电源/工业控制** | 大批量，标准元件为主 | 波峰焊 S-WS450 + S7020T |
| **新能源/BMS** | 大电流连接器，异形元件多 | S-70LD + 定制供料器 |
| **东南亚工厂** | 新厂建设，整线采购，预算有限 | 整线方案，含 AGV |

### 1.2 地域优先级

**第一梯队**（制造业转移热点，政策友好）：
- 越南（河内/胡志明）、墨西哥（Queretaro/Guadalajara）
- 匈牙利、波兰、捷克

**第二梯队**（成熟市场，性价比驱动）：
- 巴西（ Manaus）、阿根廷、印度

**第三梯队**（高利润，CE 认证优先）：
- 德国、法国、英国（汽车电子）

### 1.3 硬过滤条件

```
排除：
✗ 仅有 1-2 名员工的小作坊
✗ 年营收 <$500K 的工厂
✗ 已有日系全自动线的客户（替代周期未到）
✗ 正在经历财务危机的客户（海关数据查询）
✓ 年营收 $5M-$500M 的 EMS/ODM 厂（核心目标）
✓ 有扩产或换线计划的工厂
✓ 使用松下/三星老设备的工厂（升级窗口期）
```

```

Day 14-30 → Breakup 邮件（给价值后退场，留门）
```

## 四、Spam 合规规则（必检）

### 4.1 禁止词库（SMT 外贸专项）

**高风险词（绝对禁止）**：
```
❌ "best price" / "lowest price" / "cheapest"
❌ "100% guaranteed" / "guaranteed ROI"
❌ "no obligation" / "risk free"
❌ "limited time offer" / "act now"
❌ "free" (机器设备不能免费)
❌ "winner" / "congratulations"
❌ "urgent" / "immediately"
```

**SMT 行业特殊注意**：
```
❌ "as good as Fuji/Yamaha" — 不要直接贬低竞品，改用 "comparable output at 60% cost"
❌ "will definitely increase your yield" — 不能保证良率
❌ "our machine never breaks down" — 绝对化表述
❌ "cheaper than any other" — 绝对低价表述
```

### 4.2 格式规范

```
✓ 使用 {{first_name}} / {{company_name}} 个性化变量
✓ 标题小写："question for {{first_name}}" 而非 "Question for {{first_name}}"
✓ 无连接符：使用句号代替破折号 "—"
✓ 预览文本：把最有价值的词放在前 60 字符
✓ 正文长度：50-90 词（纯英文）；中文开发信 ≤200 字
✓ 每封邮件只突出一个核心卖点
✓ 3:1 原则：3句关于他们，1句关于我们
✓ 落款包含完整联系信息（含物理地址，满足 CAN-SPAM）
```

### 4.3 退订和关闭行规则

**禁止（以沉默换停止）**：
```
❌ "If I don't hear back, I'll assume you're not interested"
❌ "I'll take silence as a no"
```

**允许（要求明确动作）**：
```
✓ "A reply of 'not for us' is enough and I'll step out of your inbox"
✓ "Just say the word and I'll stop"
✓ "Feel free to ignore this"
```

## 六、Campaign 执行流程

### 6.1 启动清单

```
[ ] 确认目标客户 ICP（国家 + 行业 + 规模）
[ ] 确认发送账号策略（简单轮换/账号隔离/分地域）
[ ] 生成邮件序列（4 封：Cold → Follow-up 1 → Follow-up 2 → Breakup）
[ ] 执行 Spam 合规检查
[ ] 验证收件人列表质量
[ ] 设置发送节奏（每天每账号 20-30 封上限）
[ ] 配置追踪（Smartlead 或 UTM 参数）
[ ] 预热：如果账号新启动，前 2 周每天不超过 5-10 封
```

### 6.2 发送节奏建议

| 阶段 | 每天发送量 | 时长 | 说明 |
|-----|-----------|------|------|
| 预热期（第 1-2 周） | 5-10 封/账号 | 2 周 | 逐步建立 reputation |
| 爬坡期（第 3-4 周） | 20-30 封/账号 | 2 周 | 观察 bounce rate |
| 稳定期（第 5 周起） | 30-50 封/账号 | 持续 | 监控回复率 |

**Bounce Rate 警戒线**：
- < 1%：优秀
- 1-2%：正常
- 2-3%：黄色预警，检查列表
- > 3%：立即暂停，验证列表

### 6.3 回复率基准

| 行业 | 冷邮件平均回复率 | Southern Machinery 目标 |
|-----|----------------|----------------------|
| SMT/EMS 设备 | 1-3% | **> 3%**（精准 ICP + 技术话术） |
| B2B 通用 | 1% | — |
| 汽车行业 | 2-4% | **> 4%**（Active Clinching 技术亮点） |

## 七、周运营节奏（Cold Email Weekly Rhythm）

### 周一：数据复盘 + 新名单启动

```
1. 检查上周发送数据（发送量/打开率/回复率/bounce rate）
2. 识别表现最好的邮件版本（Subject/Body）
3. 导出上周回复名单，标记已回复客户 → 分配销售跟进
4. 启动新一批名单的 Cold Email
```

### 周三：跟进 + 优化

```
1. 发送 Day 3-5 Follow-up 1 给上周未回复的 Cold Email
2. 分析打开率低的 Subject Line → 替换备选标题
3. 测试新的邮件变体（A/B 测试）
```

### 周五：Breakup + 归档

```
1. 发送 Day 7-10 Follow-up 2 或 Breakup 给 14 天无回复的客户
2. 归档本周campaign数据
3. 更新 ICP 画像（根据本周回复客户的共同特征）
```
