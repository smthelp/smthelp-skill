## 核心主张与打法

### 价值定位
**"替代昂贵的日系设备（Fuji/Yamaha/Panasonic），帮客户节省 30%-50% CapEx，同时确保 High ROI。"**

主打整线方案（而非单机器）：
> Loader → Printer → Pick & Place → Reflow → AOI → THT Insertion (Axial/Radial/Terminal/Odd Form) → Wave Soldering → Unloader

### 销售模型
- **FABE**: Feature → Advantage → Benefit → Evidence
- **COSTAR**: Context → Objective → Style → Tone → Audience → Response
- **利他思维**: 所有对外内容都以"为客户创造价值"为核心，而非单纯推销
- **销售金字塔**: 从认知 → 兴趣 → 欲望 → 行动逐层推进

### 客户开发流程（标准SOP）
1. **背景调查**: 用海关贸易数据 (环球仪器 Universal)、LinkedIn、官网、客户主动公开数据（年报/LinkedIn帖文）做背调
2. **痛点分析**: 识别客户在 THT 自动化上的具体挑战（人工成本/良率/产能）
3. **精准开发信**: 用 FABE/COSTAR 模板，配合客户调研结果定制内容
4. **跟进序列**: 3-5 封邮件序列，无回复则激活老客户模板
5. **Demo/打样**: 邀请客户寄 PCB 板和元件做样品测试，签 NDA，提供评估报告
6. **方案定制**: 根据样品结果出具 含机器配置 + Feeder/Nozzle 定制的完整方案
7. **促成成交**: 谈判、交货、售后

### 客户分类标准
- **EMS 工厂**: 接受订单生产的电子代工厂（核心客户群）
- **ODM**: 原创设计制造商
- **打样/小批量**: 需要灵活配合的工厂
- **Target 联系人优先级**: CEO > 工程经理 > 采购经理

### 异议处理
使用 **"Feel-Felt-Found"** 话术：
> "我理解您的顾虑（Feel）... 其他客户也有过同样的担忧（Felt）... 他们发现我们的设备在精度和寿命上都达到了日本设备的水平，而且节省了大量成本（Found）"

针对"中国制造精度/寿命"疑虑：提供 CE 认证、CE 证书、海外工厂案例视频。

## 对外沟通规范

### 发邮件前必检清单
- [ ] 标题是否个性化（客户公司名/产品名）
- [ ] 第一句话说清楚"我是谁 + 为什么找您"
- [ ] 是否有明确的 CTA（预约视频会议/要样品/要报价）
- [ ] 是否用了 COSTAR/FABE 模型
- [ ] 签名是否包含完整联系方式

### 邮件风格
- **专业型**: 正式、数据驱动、强调技术优势
- **友好型**: 亲切、易懂、建立信任感
- **问题解决型**: 直接戳客户痛点，给出方案

### 跟进规则
- 首次邮件 → 3天后跟进 → 7天后第二次跟进 → 激活老客户邮件（如果已联系过）
- 无回复激活邮件模板：有新动态（展会/新产品/成功案例）才发，避免单纯催促
