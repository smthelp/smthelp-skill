# 客户资质判断框架 — Jason Wu 个人邮件智能体用

## Inbound 邮件分类流程

```
收到邮件
  │
  ├─ 是否来自 @gmail.com / @qq.com / @163.com 等个人邮箱？
  │     └─ ❌ → 可能是非目标客户，查 LinkedIn 验证公司背景
  │
  ├─ 邮件内容是否提到具体产品/元件/产量？
  │     └─ ✅ → 有具体数字 = 热线索（优先 A 级）
  │
  ├─ 是否提到采购时间（"尽快"/"Q3"/"6个月内"）？
  │     └─ ✅ → 有时间压力 = A 级
  │
  ├─ 发件人职位是什么？
  │     ├─ CEO / Plant Manager / Procurement Director → A 级候选
  │     ├─ Engineering Manager / NPI Manager → B 级（技术对接）
  │     ├─ Purchasing Clerk / Admin → C 级（找对人再跟）
  │     └─ Sales / Trader / Distributor → ❌ 过滤（不是终端用户）
  │
  └─ 邮件是否提到预算或投资规模？
        └─ ✅ → 有范围或具体数字 = 优先跟进
```

## 意向度评级标准

### A 级 — 高意向（立即跟进）

**必须满足 ≥2 条**：
- [ ] 明确提到要报价或要规格书
- [ ] 提到了具体产品型号或元件类型
- [ ] 提到采购时间（Q3/尽快/6个月内）
- [ ] 公司年营收 ≥$10M（可从 LinkedIn 查）
- [ ] 发件人是决策层（CEO/Plant Mgr/Procurement Dir）

**行动**：
- 2小时内回复
- 发送详细方案 + 产品规格书
- 主动预约视频会议

### B 级 — 中意向（24小时跟进）

**满足任意 2 条**：
- [ ] 问了产品系列或行业解决方案
- [ ] 公司在 LinkedIn 上有明确 SMT/THT 产线描述
- [ ] 邮件语气专业，但未提具体需求
- [ ] 批量询问（「你们有什么设备？」）

**行动**：
- 24小时内回复
- 提供匹配产品组合资料
- CTA：预约技术通话或发送规格书

### C 级 — 低意向（加入序列）

**满足任意 1 条**：
- [ ] 邮件语气泛泛，无具体需求
- [ ] 来自非目标地区或非目标行业
- [ ] 发件人职位不明确或明显无决策权
- [ ] 只是打听价格而无实质采购计划

**行动**：
- 简短回复，保持专业
- 加入 EDM 跟进序列（Day 0 → Day 3 → Day 7 → Day 14-30）
- 不要立即电话，邮件序列足够

### D 级 — 不合格（礼貌过滤）

**满足任意 1 条**：
- [ ] 竞代/贸易商（中间商，无实际生产设施）
- [ ] 公司规模 < 10 人
- [ ] 要求免费样品/免费试用（不适合设备）
- [ ] 要求提供竞争对手报价单
- [ ] 明显垃圾询盘

**行动**：
- 简短礼貌回复
- 不加入跟进序列
- 不打电话

## 快速判断问题清单（发邮件前自问）

```
□ 客户是终端用户吗？（不是贸易商）
□ 有明确需求吗？（不是泛泛了解）
□ 有采购时间线吗？（不是"以后再说"）
□ 有预算可能性吗？（不是"太贵了不考虑"）
□ 找对人了吗？（不是 Admin 发来的）
□ 我有竞争优势吗？（客户目前用什么？）
□ 客户能负担得起我的方案吗？（不是资金链断裂）
```
