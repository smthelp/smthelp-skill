# Southern Machinery 企业知识库
**Southern Machinery（南方机械）** — 成立于2011年，深圳。专注为全球EMS/ODM代工厂提供高效率、高性价比的SMT/THT自动化整线解决方案。

---

## 一、公司核心价值主张

### 1.1 定位
源头工厂，直接研发与制造。专注出口导向的海外大客户（年营收$5M~$500M的EMS/ODM厂）。

### 1.2 核心竞争优势
- **极致性价比**：相比日系设备（Fuji, Yamaha, Panasonic）节省 **30%-50% CapEx**
- **一站式整线交付**：SMT → THT → 波峰焊 → 板传输与检测全覆盖
- **高ROI**：同样的预算买更多产能，2-3年回本周期
- **CE认证**：产品符合欧盟安全标准

### 1.3 典型客户画像
- 年产100万~5000万点数的EMS代工厂
- 有意降低设备采购资本支出的SMT/THT车间
- 需要整线升级或新建的海外电子厂（东南亚、东欧、南美制造成趋势）

### 1.4 异议处理 — "Feel-Felt-Found" 话术
> **"我理解您的顾虑。很多客户最初也有同感——担心中国制造的精度和使用寿命。"**

## 二、全产品线详细规格

### 2.1 SMT整线方案

#### 高产能方案（35K CPH）
- **总价**：~$163,888
- **核心配置**：全自动上板机 → 全自动锡膏印刷机 → 高速贴片机（35,000 CPH）→ 回流焊 → 自动光学检测（AOI）

#### 高性价比方案（25K CPH）
- **总价**：~$138,800
- **核心配置**：半自动上板机 → 锡膏印刷机 → 中速贴片机（25,000 CPH）→ 回流焊 → AOI
- **适用场景**：中小批量、多品种换线频繁的EMS厂

**BF-2002D vs SBF1001 选择**:
- 客户产线空间紧张（双层节省空间）→ **BF-2002D**
- 客户已有SBF平台或只需单碗 → **SBF1001**
- 客户需要并行供两种料 → **BF-2002D双层**（双碗独立）
- 客户P&P是 Panasonic CM602 / Juki / Fuji / ASM → **BF-2002D 已验证兼容**

#### 异形件夹爪 / 吸嘴（Gripper Nozzle）

BF-2002D / SBF1001 出来的物料，P&P机不能用普通真空吸嘴抓取（立方体+凸起特征），必须配 **Gripper Nozzle 夹爪式吸嘴**：

- **固定臂 + 摆臂结构**：抓取异形件本体，避开顶部凸起
- **定制橡胶指尖（rubber tips）**：可换装，适配不同零件
- **接口匹配**：Juki 503/504、Panasonic CM nozzle、Fuji 等
- **典型应用**：异形连接器、混合电路、立方体金属件、顶部有螺丝/凸起的端子

### 2.9 异形件供料选型决策树（**日常快速参考**）

```
客户问"X零件自动化" → 第一步：看包装形式
│
├── 编带 Tape-and-reel（电阻/电容/SMD）   → 标准SMT Feeder / SRF1001（径向）
├── 管装 Tube/Stick（继电器/变压器/小电容） → STF1003
├── 托盘 Tray（连接器/BGA/大方形件）        → STP1001
├── 卷盘 Reel（reel terminal / 跳线）       → SRT7001
├── 标签 Label（QR码/MES标签）             → SLF1001
├── 散装 Bulk（螺丝/螺母/垫片/金属端子块/弹片）→ ★ BF-2002D 或 SBF1001 + 定制Gripper Nozzle
│
└── 客户是THT插入（tab穿过PCB孔）还是SMT贴装（元件在板面）？
    ├── SMT贴装 → BF-2002D/SBF1001 + 客户P&P
    └── THT插入 → SBF1001 + S-70LD / S-7900 异形插件机（带Active Clinching主动折弯）
```

**与下游设备的协同配置**:
- **SMT 贴装场景**: BF-2002D → 客户P&P（Panasonic/Juki/Fuji/ASM）→ AOI → Reflow
- **THT 插入场景（高可靠性）**: SBF1001 → S-70LD 异形插件机 → Wave Soldering
- **汽车级/IPC-610 Class 3**: 必须 S-7900 + Active Clinching（机械备份焊点）
- **混合方案**: 客户已有P&P但需要高可靠性插入 → P&P 放SMT料 + S-70LD 单独跑THT

**为客户出方案前必问的8个问题**（写进 Proposal 信息请求段）:
1. 零件准确尺寸 + 2D/3D 图纸
2. 月产量 / 年产量
3. 现有 P&P 品牌型号
4. 现有工艺流程（已过回流？板面是否有冲突元件？）
5. 焊接工艺（波峰焊 vs 选择性焊）
6. 是否需要 UL / TUV / NOM（墨西哥强制）等认证
7. 工厂位置（墨西哥 Reynosa / Juarez / 其他）
8. 目标交付日期 + 是否需要墨西哥现场安装支持

## 三、销售话术与邮件模板

### 3.1 FABE法则应用
> **F**eature（特性）：设备有什么 → "我们的S-7900有4个插件头，AI视觉校正"
>
> **A**dvantage（优势）：这个特性意味着什么 → "这意味着每小时可插入4000个元件，精度±0.05mm"
>
> **B**enefit（利益）：对客户有什么好处 → "对您来说，这意味着一条线可以替代6-8个工人，每月节省人工成本$8,000以上"
>
> **E**vidence（证据）：证明这一切 → "我们的客户A工厂使用后，2年内就收回了设备投资"
