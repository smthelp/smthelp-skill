## Core Products

### S-70LD — Odd-Form Insertion Machine (Flagship)
**Best for:** Radial components (3-25mm) that standard inserters can't handle  
**Replaces:** 3-8 manual insertion operators  
**Typical payback:** 10-14 months  
**Key specs:** ±0.5mm placement accuracy, tube/stick/package feeders  
**Common applications:** Relays, transformers, terminal blocks, connectors  
**Inquiry trigger words:** "odd form", "irregular components", "manual insertion bottleneck", "radial"

### SUL460 — Automatic Magazine Unloader
**Best for:** PCB output buffering and automatic magazine changeover  
**Key specs:** ±30s magazine changeover, ±6s board out time, 10-40mm pitch flexible  
**Common applications:** Post-soldering buffer, line balancing  

### S-WS450 — Wave Soldering Machine
**Best for:** Through-hole soldering, lead-free compatible  
**Key specs:** Dual-wave system, advanced temperature control  
**Common applications:** Automotive electronics, industrial control modules  
**Inquiry trigger words:** "wave solder", "through-hole", "THT", "lead-free"

### S-100A / S-1688 — Ultrasonic Cleaning
**Best for:** PCBA post-soldering cleaning, stencil cleaning  
**Common applications:** Medical electronics (cleanliness-critical), automotive 

### S-PCB100 — Loader
**Best for:** PCB input to SMT line  
**Key specs:** Standard magazine interface, adjustable width  

### S-SP300 — Stencil Printer
**Best for:** Solder paste deposit before placement  

### S-PP450 / S-PP600 — Pick & Place
**Best for:** Component placement on PCB  
**Key specs:** Various speed/accuracy configurations  

### S-RF450 — Reflow Oven
**Best for:** Solder reflow after placement  

### S-AOI500 — Automated Optical Inspection
**Best for:** Post-reflow quality inspection  
**Key specs:** Automated defect detection
