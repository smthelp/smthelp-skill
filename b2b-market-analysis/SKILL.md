## 工作流程

### Phase 1 — 收集用户输入
请用户提供：
1. 产品名称（精确，含型号/类别）
2. HS 编码（如知道，加速关税查询）
3. 目标出口国家/区域
4. 公司类型（工厂 / 贸易公司）
5. 现有出口经验（可选）

### Phase 2 — 竞品情报深度抓取 (Competitive Intelligence)

在搜索认证/关税之前，先建立竞争格局全景图：

#### 2.1 竞品识别
用 web_search 搜索以下 query：
- `"{product} manufacturers in {country}"` — 该市场的主要供应商
- `"top {product} suppliers {country}"` — 行业排名/目录
- `"{product} {country} importers buyers"` — 采购商视角看竞品
- `"{product} price list {country} 2026"` — 竞品定价线索

#### 2.2 竞品网站分析
找到 3-5 个主要竞争对手的官网，用 web_fetch 提取：
- 产品线覆盖范围（你的 gaps / 他们的 gaps）
- 认证展示（他们有的认证 → 你也需要的认证）
- 定价信号（MOQ、价格区间、促销活动）
- 客户案例/背书（了解他们攻下了哪些客户）
- 官网 SEO 关键词密度（他们在优化什么搜索词）

#### 2.3 竞品广告与社媒分析
搜索竞品在各平台的曝光：
- LinkedIn：搜 `"{competitor}"` — 看公司规模、员工增长、内容策略
- Alibaba / MIC：搜竞品公司名 — 看产品列表、价格、交易记录
- Facebook/Instagram Ads Library：搜竞品品牌 — 看广告投放策略
- YouTube：搜竞品产品名 — 看视频营销内容

输出「竞品情报矩阵」：

| 竞品 | 国家 | 产品线 | 价格信号 | 认证 | 渠道策略 | 我们的差异化空间 |
|------|------|--------|---------|------|---------|----------------|
| XXX  | ...  | ...    | ...     | ...  | ...     | ...            |

### Phase 3 — 市场情报搜索（必须 web_search）
用 web_search 搜索以下信息：
1. 目标国该产品的**进口关税税率**及最新贸易政策变化
2. **强制认证要求**（CE / FDA / UL / SONCAP 等）
3. 推荐认证（非强制但市场普遍认可的）
4. 主要竞争对手在该国的市场分布
5. 行业展会信息（该国的垂直展会）

### Phase 4 — 生成作战地图

#### 3.1 战场环境分析
- 该国 B2B 采购渠道结构（进口商层级 / 分销网络 / 终端用户）
- 主要进出口港口/物流节点
- 商业文化注意事项（沟通习惯、谈判风格、付款偏好）

#### 3.2 市场进入规则
- 强制认证清单（含认证机构链接）
- 推荐认证清单
- 关税税率（HS 编码级别）
- 进口特殊限制（如有）

#### 3.3 关键词武器库
- **价值词**（触发情感共鸣的 10 个词）：如 reliable partner, cost-effective, turnkey solution
- **搜索词**（高购买意图关键词）：product + country + buyer/importer/distributor
- **长尾问题词**（客户搜什么问题的答案）："how to find reliable [product] supplier in China"

#### 3.4 黄金 3 秒 Hook
- 邮件主题行（2-3 个）
- LinkedIn 开场白（2-3 个）
- WhatsApp 第一句（1-2 个）

#### 3.5 行动路线图
- 第一优先级行动（认证/注册）
- 第二优先级行动（渠道触达）
- 第三优先级行动（客户开发）
- 时间建议

**海外市场分析完整框架**（五步法）：
1. 行业与市场调研——行业报告（行业规模/增长率/趋势）+海关数据（出口数据看体量）+Google Trends（需求稳定性/淡旺季）+亚马逊销售数据（找体量大的SKU/对标价格带/看差评找改进点）
2. 客户类型细分——美容院/培训机构/品牌零售商/个人用户/批发商（每类标明：需求稳定性/品质要求/体量/地理分布）
3. 市场定位9问——企业有差异性资源吗？资源能聚焦形成区隔吗？目标客户群体清晰吗？价格定位合理吗？渠道匹配吗？品牌认知度如何？竞品强弱项？市场进入壁垒？政策风险？
4. 渠道设计——B端做份额（阿里+SEO+SEM+社媒+展会+地推+海关数据）+C端做品牌（Amazon+独立站+众筹+网红+社交媒体）
5. 团队与执行——稳定区域高底薪低提成/待开发区域中底薪高提成。R&D提供参数+采购提供成本+生产提供交期+营销提供素材+销售提供反馈+物流提供运费

**从亚马逊差评找产品改进思路**（实用方法）：搜索目标品类→筛选1-3星评价→提取高频投诉关键词→对照我方产品找到差异化切入点→把"别人被投诉的点"变成"我们的卖点"

**竞品分析维度**：公司规模、主营产品线、价格带、海外仓布局、主要客户群体、营销渠道（独立站/社媒/B2B/展会）、月销量估算、客户评价关键词、产品弱点

**语言规则**：分析框架可用中文，关键词和客户可见内容（Hook、搜索词）用英文。
