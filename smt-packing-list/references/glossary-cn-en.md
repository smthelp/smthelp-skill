# 术语中英对照（Packing List）

| 中文 | PL 上的英文写法 | 说明 / 常见错误 |
|---|---|---|
| 装箱单 | PACKING LIST | 不写 "Packing list"（标题全大写） |
| 装箱单号 | PL No. | = 同票商业发票号；不写 "PL#"、"NO:" |
| 发票号 | Invoice No. | |
| 采购单号 | PO No. | 不写 "PO#" |
| 日期 | Date | `04 May 2026`；不写 "4-Mar-2026"、不用 =NOW() |
| 卖方/出口商 | Seller / Exporter | 不写 "MANUFACTURER"（我们多数不是制造商） |
| 收货人 | Consignee | 不写 "Ship to.:" |
| 通知方 | Notify party | 有就加 |
| 联系人 | Attn | |
| 装运港 | Port of loading | Shenzhen, China |
| 目的地 | Destination | |
| 贸易术语 | Delivery terms | `EXW Shenzhen, China (Incoterms® 2020)`，与发票一致 |
| 原产国 | Country of origin | China；不写 "The People's Republic of China" + "PLACE: CHINA" 两处重复 |
| 箱号 | C/No. | `1-4`、`1/1` |
| 件数 | Packages | `4 cartons`；不写 "QTY OF CTNS"、"QTY OF Crate" |
| 纸箱 | Carton(s) | 不写 "CTNS 1#"、"Box 1#" |
| 木箱 | Wooden crate(s) | 必须加 ISPM 15 / IPPC 声明 |
| 托盘 | Pallet(s) | |
| 免熏蒸 | ISPM 15 heat-treated, IPPC marked | 胶合板箱可写 "plywood, exempt from ISPM 15" |
| 品名描述 | Description of goods | 第一行 SM 型号 + 英文品名 |
| 用途 | Function | |
| 材质 | Material | `copper, PVC`；不写小写 "pvc"、"pc" → `PC (polycarbonate)` |
| 序列号 | S/N | 机器必填（BOI、保修、清关） |
| 海关编码 | H.S. code | 与发票一致，报关行确认 |
| 数量 | Qty | 单独一列，不写在品名后 "* 1" |
| 单位 | Unit | pcs 个 / set 台(套) / sets / rolls 卷 / pairs 对 |
| 净重 | N.W. (kg) | 不写 "Net weight（KG）" 全角括号 |
| 毛重 | G.W. (kg) | ≥ 净重 |
| 尺寸 | L × W × H (cm) | 不写 "(60*40*40)cm"、"200*190*190" |
| 体积 | CBM (m³) | 4 位小数 |
| 合计 | TOTAL | |
| 唛头 | Shipping marks | 买方、目的地、PO、PL/发票号、箱号、MADE IN CHINA |
| 非危险品 | Non-dangerous goods | 不写 "NO DANGEROUS" |
| 授权签字 | Authorized signature & company stamp | 签字人姓名印在线下 |
| 代表…签署 | For and on behalf of | |
| 香港 | Hong Kong | 不写 "Hongkong" |
| 有限公司（香港） | Co., Limited | 不写 "Co.,Limited,China" |
| 宝安区 | Bao'an District | 不写 "Banan District"（重庆巴南） |
