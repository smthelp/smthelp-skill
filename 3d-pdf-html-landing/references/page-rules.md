# Page Rules

## Claims

- Treat a 3D PDF as a visual source, not as a verified specification sheet.
- Use "to be confirmed" for unverified speed, dimensions, delivery time, price, warranty, or certification.
- If PRC/U3D is detected, write "embedded 3D stream detected" rather than promising browser-native PRC playback.

## SEO Structure

- Title: include product name + "Interactive 3D" + Southern Machinery.
- Meta description: include the product category and PCB assembly automation.
- H1: product name derived from the filename.
- First viewport: logo, interactive 3D viewer, CTA, and source note.
- JSON-LD: use `Product` with `Organization` manufacturer.

## WebGL Fallback

If the canvas cannot initialize, keep all textual content visible and show a short message:
"WebGL is unavailable in this browser. Product details remain available below."
