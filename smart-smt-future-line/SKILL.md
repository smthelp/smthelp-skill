# Smart-SMT Future Line

Create futuristic 16:9 English marketing visuals for Southern Machinery. This version is more energetic than the clean industrial style: glowing PCB paths, dark graphite panels, cyan motion lines, precise machine silhouettes, and modern factory depth.

Use it for YouTube thumbnails, campaign hero images, product launches, and high-impact LinkedIn visuals.

## Read When Needed

- `references/style-dna.md`: future-line visual DNA, palette, and intensity limits.
- `references/composition-patterns.md`: production-line and high-tech composition patterns.
- `references/prompt-template.md`: imagegen prompt template.
- `references/qa-checklist.md`: validation and iteration checklist.
- `assets/southern-machinery-logo-300x83.png`: official Southern Machinery logo reference asset. Use this PNG when a logo is needed; do not redraw, approximate, or replace the logo with plain text.

## Workflow

1. Identify the channel: YouTube thumbnail, landing page hero, LinkedIn campaign, blog hero, or product banner.
2. Choose one process hero: SMT placement, THT insertion, full line flow, AOI inspection, wave soldering, board handling, or LED + lens assembly.
3. Write one short English headline first. Keep it 2-6 words if it appears inside the image.
4. Generate 1-3 imagegen prompts as separate images. Each prompt must have one dominant focal point.
5. Use futuristic cues carefully: glow should show motion and precision, not become cyberpunk decoration.
6. Add a human-review note for any formal technical or commercial claim.

## Shot List Format

```markdown
## Concept 1: [Name]
Use: [where this image fits]
Message: [one focused business point]
Visual: [one-sentence image idea]
English text: "[exact text or no text]"
Imagegen prompt: [prompt]
```

## Brand Notes

Southern Machinery is an automation partner for global EMS / PCB assembly factories. Keep the tone confident, practical, and engineering-led. Avoid fake UI dashboards, exaggerated speed claims, and unverified ROI badges.
