# Composition Patterns

Choose one structure per image.

## Glowing Process Line

Best for complete-line and landing-page visuals.

Composition: a clean production line in perspective with one cyan PCB path connecting stations.

## Precision Beam

Best for placement, insertion, AOI, and soldering topics.

Composition: close-up machine head or sensor aligned to a PCB using cyan guide lines. Keep the background minimal.

## Future Factory Corridor

Best for campaign hero images.

Composition: modular machines recede into depth. One PCB panel or glowing conveyor path leads the eye.

## Upgrade Portal

Best for manual-to-automation campaign visuals.

Composition: left side shows manual work simplified; right side shows a bright automated line. Use a light gate or cyan path to connect the transition.

## Originality Rule

Do not reuse original Xiaohei low-tech metaphors. This version should translate "one clear visual idea" into industrial high-tech language.
