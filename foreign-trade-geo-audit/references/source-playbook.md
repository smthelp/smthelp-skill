# 站外信源检索打法 · Phase 4 执行手册

> Phase 4 是整个评估里**唯一不能靠脚本、也不能靠官网内容替代**的环节。
> 跳过它，报告就只是"网站体检"，不是"GEO 评估"。

## 一、必跑的三类词

| 词型 | 目的 | 示例（SMT 行业） | 看什么 |
|---|---|---|---|
| **品牌词** | 实体是否被归对 | `"Southern Machinery"` / `"Shenzhen Southern Machinery Sales and Service Co., Ltd."` | 答成别家？地址业务归对？有无同名干扰？ |
| **场景词** | 召回广度 | 见行业画像的 `scenario_queries` | 你是否在列、排第几、**AI 引用了谁** |
| **人物词** | 个人实体反哺 | `"Jason Wu" SMT` | 能否带出公司实体 |

**人物词是见效最快的词**——个人权威度积累快于企业，且同名干扰通常更少。

## 二、核心动作：记录引用来源清单

```
对每一个问题，记录：
  问题: "..."
  AI 回答要点: ...
  AI 引用的网址: [a.com, b.com, c.com]   ← 这一行是金矿
  是否提到我们: 否
  提到了谁: [竞品1, 竞品2, 竞品3]
```

**引用来源清单 = 信源缺口地图。** AI 引了谁，你就去哪里布局：
- 引了行业媒体 → 去投稿
- 引了 B2B 平台 → 去完善企业档案
- 引了百科 → 去建词条
- 引了评测站 → 去争取收录
- 引了竞品官网 → 说明竞品的内容结构更合引擎口味，去研究它

## 三、独立信源判定标准

**算作独立信源（他证）**：
- 行业媒体 / 协会报道
- B2B 平台官方企业档案（非自家发布的产品页）
- 百科词条
- 第三方评测 / 榜单
- 客户方发布的内容（客户官网、客户社媒提到你）
- 政府 / 园区 / 展会官方名录
- 图书 ISBN、论文、专利

**不算独立信源（自证）**：
- 自己的官网（含多语种分站）
- 自己的社媒账号（LinkedIn / FB / X / YouTube）
- 自己的微信公众号、头条号、知乎机构号
- 自己在 B2B 平台发布的产品信息

> 招聘平台（BOSS 直聘等）算**弱第三方**：平台独立但内容由企业自己填写，权重有限。

## 四、各行业的权威信源类型

见 `config/industry-profiles.json` 的 `authority_source_types`。SMT 行业示例：
- IPC / SMTA 协会与社区
- 电子制造类行业媒体
- YouTube 产线实拍（多模态权重上升）
- 产品手册与 Gerber 图纸库
- B2B 平台企业档案

## 五、检索执行清单

```
□ 品牌词 × 2（全称 + 常用简称）
□ 场景词 × 行业画像全部 scenario_queries
□ 人物词 × 1
□ 对每个问题记录"AI 引用了哪些网址"
□ 统计独立信源数量与占比，回填 --manual
□ 标注场景词前列被哪些竞品占位
□ 把引用清单整理成"信源缺口地图"，放进报告的 D 维度证据
```

## 六、回填评分

把统计结果写成 JSON 传给 `geo_score.py`：

```json
{
  "independent_source_count": 1,
  "independent_ratio": 0.1,
  "scenario_word_presence": 0.0,
  "founding_year_consistent": true
}
```

```bash
python3 geo_score.py --scan scan.json --manual manual.json --out score.json
```

`scenario_word_presence` 取值参考：
- `0.6+` 多数核心场景词能看到你
- `0.3` 约三分之一能看到
- `0.1` 偶尔出现
- `0.0` 完全缺席

## 七、盲测（补充 F 维度）

盲测题由报告模板的 T1–T6 生成，执行要求：
- **每题开新会话**（避免上下文污染）
- 五平台各问一遍：豆包 / DeepSeek / 元宝 / 文心 / Kimi
- 同一题**隔 3 天复测**看稳定性
- 截图存档

F 维度不计入综合分——**任何推演都不能替代实测**。
