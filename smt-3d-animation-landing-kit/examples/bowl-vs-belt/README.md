# bowl-vs-belt (reference only)
First job (2026-10-21): SBF1001 vibratory bowl feeder vs S-MVF01 reciprocating belt feeder.
Contains the FeederDuel animation (`duel.js`, chapters principle/speed/space/gentle/change/verdict), the narration (`script.json`)
and the video stage (`video.html`). To rebuild it as a job: `smt3d.py init jobs/bowl-belt --example stf1003-tube-feeder`, then replace
duel.js/script.json/video.html with these files, set `duel.class = "FeederDuel"`, `duel.keys = ["bowl","belt"]` and rewrite content.json.
Published page: https://file.autoinsertion.com/public/Product%20landing%20Page/bowl-vs-belt-feeder-sbf1001-vs-s-mvf01-comparison.html (if uploaded).
