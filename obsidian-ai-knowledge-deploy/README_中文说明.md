# Obsidian AI 知识库部署总控 中文说明

## 这是什么

这是从 `本包自研` 抽取出来的 Agent Skill 源码目录。客户 Agent 可以直接读取本目录的 `SKILL.md`，按其中流程执行。

## 能干什么

用于补充 Agent 的专项工作能力。具体能力以本目录 `SKILL.md` 为准。

## 怎么安装

1. 确认目标 Agent 支持 Skill。
2. 将本目录复制到目标 Agent 的 Skill 目录。
3. 让 Agent 读取 `SKILL.md`。
4. 若本目录含 `scripts/`、`references/`、`assets/`，一并保留。

## 怎么验收

Agent 能复述步骤并运行客户自检。

## 来源

- 原仓库：本包自研
- 抽取路径：本包自研
- 作者/组织：AI-Skill 商品化工作流工厂
- 许可证：随商品包说明
