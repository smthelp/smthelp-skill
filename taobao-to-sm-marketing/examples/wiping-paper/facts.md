## 1. How a size is written (VERIFIED - corrects the brief)
- Listing size `410 x 300 x 10 m` = **core (tube) length 410 mm x paper width 300 mm x paper length 10 m**.
  Evidence: E i-010/i-025...i-040 captions "管长 410mm 纸宽 300mm 纸长 10m"; D i-058 drawing "管长 410 / 纸宽 300 / 内直径 20 / 外直径 23";
  reference table A i-028 / E i-047 / F i-050 header "管内径 / 管长 / 纸宽 / 纸长(M)"; J writes "DEK 300*10m*530" (width x length x tube).
- So the first number is NOT the paper width and the second is NOT the roll OD. Roll OD of a 10 m roll is ~50 mm (E i-055 example).
- Example roll (E i-055): core ID 20 mm, core length 470 mm, wall 1.5 mm, core OD 23 mm, finished roll Ø 50 mm, paper width 450 mm, 10 m; sizes hand-measured ±1 mm.

## 3. Material and performance
- Natural wood pulp + polyester, hydroentangled (spunlace, 水刺法), wood pulp / polyester two-layer structure (B text; I i-009). VERIFIED.
- Soft, low lint ("表面毛屑接近于零", "不掉尘"), absorbs water and oil/solvent, strong and tough, usable with cleaning solvents, anti-static packing (B text). VERIFIED (supplier claims).
- Removes excess solder paste and red glue from stencils and PCBs (B text).
- Composition: **55% wood pulp / 45% polyester** (E i-054, A i-023 data sheet) vs **45% wood pulp / 55% polyester** (G, I i-009) -> TO BE CONFIRMED (by version / supplier).
- F lists main material "polyester, nylon composite fibre" -> TO BE CONFIRMED.
- Basis weight: 56 g/m2 plain weave (J params) vs 60 ± 3 g/m2 (A i-023 data sheet) -> TO BE CONFIRMED.
- One supplier data sheet (A i-023, company standard, 410x350xΦ20x10m, cross slot): thickness 0.35 mm, absorption speed 2.08 s/5 cm, liquid absorption 589 %, breaking strength CD 30.04 / MD 139.63 N/5 cm, elongation CD 138.72 / MD 32.78 %, test standard FZ/T 64012. Single-source -> publish only as "typical, one data sheet, confirm per batch" or not at all (used: thickness 0.35 mm as TBC in spec table; rest kept here).
- E i-054: absorption ≤ 0.5 s (different method/unit than A) -> TO BE CONFIRMED, not published.
- Surface types: plain weave (平纹) and mesh / grid (网格) (D i-058); PP / mesh perforated type offered (H title "网孔pp", C title "PP", H i-025 images). Exact PP construction -> TO BE CONFIRMED.
- Compatible printers (B text, E i-054): MPM, DEK, KME, YAMAHA, MINAMI, JUKI, EKRA, PANASERT (Panasonic), FUJI, SANYO "and all fully automatic printers with auto wipe".
- Rolls shrink-wrapped and packed in cartons (E i-013 photo).
