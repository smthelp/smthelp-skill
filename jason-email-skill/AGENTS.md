# Jason Wu 邮件 Skill — Agent 使用说明

## 快速入口

当用户要求写邮件时，加载此 skill 并按以下步骤执行：

```
1. 读取 SKILL.md 全文（理解邮件类型、框架、模板）
2. 询问或根据已有信息判断：
   - 邮件类型（冷启动/跟进/Breakup/其他）
   - 目标客户（公司名、行业、国家、联系人姓名和职位）
   - 客户痛点或需求（如果没有提供，基于客户行业推断）
   - 目标产品（如果没有提供，推荐 Southern Machinery 整线方案）
3. 根据模板库选择最合适的模板
4. 用客户真实信息替换所有 [占位符]
5. 对照「发件前检查清单」核对
6. 按规范格式输出
```

## 不要这样做

- ❌ 不要手写 challenger 版本绕过官方模板
- ❌ 不要在邮件中堆砌 Southern Machinery 所有产品卖点
- ❌ 不要使用"Great question!" "I'd be happy to help!" 等废话开头
- ❌ 不要在 Cold Email 中使用"希望您百忙之中抽出宝贵时间"
- ❌ 不要在客户未表现出兴趣前发送报价或详细方案

## 输出规则

如果用户要求多版本（中文/英文、版本A/版本B），同时输出所有版本，并在开头注明推荐版本。

## 邮件类型判断

| 关键词/场景 | 推荐邮件类型 |
|-----------|------------|
| 首次联系、不知道我们、陌生客户 | Cold Email |
| 之前发过没回复、3-5天后 | Follow-up 1 |
| 7-10天没回复、有新动态 | Follow-up 2 |
| 14-30天完全没回复 | Breakup 唤醒邮件 |
| 展会前4-6周邀约 | Expo Invitation |
| 报价/方案发出后 | Proposal Follow-up |
| 客户投诉或出问题了 | Crisis 邮件 |
| 半年以上没联系的老客户 | Reactivation 激活邮件 |

## 产品推荐逻辑

```
客户有异形元件插入需求 → S-70LD（通用）或 S-7900（高产能/汽车级）
客户有端子/连接器插入 → S-7020T
客户有多品种换线需求 → S-7900 + AI视觉
客户问波峰焊 → S-WS450
客户需要整线 → Loader→SMT→THT→波峰焊→Unloader 全线
客户预算紧张 → 从 S-70LD 单机切入，后续扩线
```
