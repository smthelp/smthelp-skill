# 市场调研（SMT 设备出口）

## 核心定位

市场调研最失败的产物是一份"行业规模达 XX 亿美元"的报告——数字大而空，没法指导任何动作。

本 skill 只回答一个决策问题：**这个市场值不值得投，如果要投，第一枪打哪里。**

---

## 触发场景

- "看看 [某国/某地区] 值不值得做"
- "准备开拓 [市场]，给我一份调研"
- "这个区域我们的机会在哪"
- 参展前评估某展会所在市场
- 年度市场优先级排序

---

## SM 硬约束

- 核心客户类型固定：**EMS / ODM / 汽车电子 / 医疗电子工厂**
- 术语保留英文：EMS、ODM、Pick-and-place、Reflow、Wave Soldering、THT、CPH、Turnkey Line
- 竞品品牌写原名：Yamaha、JUKI、Panasonic、ASM (SIPLACE)、Fuji、ERSA、SEHO、Soltec
- **禁止编造市场数据**。所有数字必须标来源与年份，查不到就写"未获取到"，不要用行业通稿里的模糊数字凑数

---

## 工作流

### Step 1：明确决策问题

先锁定这次调研要支撑哪个决策，不同决策需要的信息完全不同：

| 决策 | 关键问题 |
|---|---|
| 要不要进这个市场 | 有多少目标工厂、他们买什么档次的设备、我们能打到什么价位 |
| 怎么进 | 直销 / 代理 / 参展 / 平台，哪种获客成本最低 |
| 主推什么机型 | 当地主流工艺是什么，混装线占比多少 |
| 参展值不值 | 这个展会的观众构成与采购决策权 |

**一次调研只回答一个决策问题。**

### Step 2：六个维度采集

#### 维度 1 — 产业基础
- 当地 EMS / PCBA 工厂数量与规模分布
- 主要终端行业（汽车电子 / 消费 / 医疗 / 工控 / 军工）
- 是否以混装线（SMT + THT）为主 —— **这直接决定 S-70LD 与 S-WS450 的机会**
- 人工成本水平 —— 决定自动化改造的 ROI 周期

#### 维度 2 — 需求特征
- 主流 PCB 尺寸与元件规格（能否支撑我们的机型能力区间）
- 典型产能诉求（CPH 区间）
- 是新增产线还是改造存量线
- 现有设备品牌构成（Yamaha / JUKI / Panasonic 的保有量决定兼容性话题）

#### 维度 3 — 准入与合规
- 认证要求（CE / UL / 当地强制认证）
- 电压与工业标准（三相电压制式）
- 关税税率与进口环节税费
- 是否需要本地代理商资质

#### 维度 4 — 竞争与价格带
- 竞品在该区域的渠道（代理 / 直销 / 二手设备商）
- 新机与二手设备（Yamaha、JUKI 二手机在部分市场占比很高，这是最大的替代威胁）
- 客户对新设备的价格心理区间
- 中国品牌在当地的既有口碑

#### 维度 5 — 触达渠道
- 本地行业展会（名称、周期、观众构成）
- 行业协会与媒体
- LinkedIn 上当地工艺工程师的活跃度
- B2B 平台在该区域的渗透率（Alibaba / Made-in-China / 本地平台）

#### 维度 6 — 客户画像
- 典型决策链：谁提需求、谁做技术评估、谁批预算
- 采购周期长度
- 付款方式偏好（L/C、T/T、分期）
- 对"中国品牌"的既有态度与常见疑虑

### Step 3：机会评分

每个维度 1–5 分，加权得出判断：

| 维度 | 权重 | 说明 |
|---|---|---|
| 混装线占比 | 高 | 我们的差异化最直接的落点 |
| 人工成本水平 | 高 | 越高，自动化 ROI 越好算 |
| 存量设备品牌 | 中 | 是否容易谈兼容性话题 |
| 二手设备冲击 | 中 | 二手占比高则新机难卖 |
| 准入难度 | 中 | 认证与关税成本 |
| 触达成本 | 低 | 展会与平台费用 |

**≥ 3.5 分重点投入，2.5–3.5 分试探，< 2.5 分暂缓。**

### Step 4：给出进入策略

不要停在"值得做"，要给第一枪怎么打：

- **主推机型**：基于工艺结构（混装线占比高 → S-70LD + STF1003；波峰焊需求强 → S-WS450 + SUL460）
- **切入角度**：算账（人工替代）/ 兼容性（接现有 JUKI 线）/ 交期（新机 vs 二手翻新周期）
- **触达路径**：展会 > LinkedIn > 平台 > 冷信，按当地有效性排序
- **试点客户画像**：什么类型的工厂最适合做第一个样板客户

## Gotchas

1. **不要堆"市场规模达 XX 亿美元"**
   解释：这个数字不能指导任何动作。要的是"当地有多少家 50 人以上的 EMS 工厂、其中混装线占比多少"这类能直接换算成潜在客户数的数据。

2. **不要忽略二手设备这个最大竞品**
   解释：在很多新兴市场，Yamaha / JUKI 的翻新二手机才是我们真正的对手。只盯新机竞品会严重高估机会。

3. **不要编造或用模糊来源的市场数据**
   解释：查不到就写"未获取到"并给出补充调研动作。一个错误的数字会导致整个市场判断跑偏，而它看起来比"不知道"更专业，因此更危险。

4. **不要混淆"有工厂"和"会买我们的设备"**
   解释：有大量 PCBA 工厂不等于有机会。要看他们的工艺结构（是否混装）、人工成本（ROI 是否成立）、以及对新设备的预算。

5. **不要跳过准入成本**
   解释：某些市场的认证与关税会把价格优势吃掉。报价前必须把这块算进去，否则会出现"谈成了却没利润"。

6. **不要给结论不给第一枪**
   解释：调研的价值在于可执行。"值得做"不是结论，"用 S-70LD + STF1003 打人工插件替代的算账角度，通过 X 展会接触 Y 类工厂"才是。
