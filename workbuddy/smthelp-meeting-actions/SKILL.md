# 客户会议纪要与行动项

## 核心定位

客户会议纪要最常犯的错是写成流水账——"客户说…我们说…"。这种纪要没法执行，也没法交接。

有效的纪要要分清楚四件事：**已确认的事实、双方做出的承诺、还没解决的异议、谁在什么时间前做什么**。

外贸场景下还多一层：海外客户会议里提到的技术参数，往往就是后续方案与报价的输入，漏记一个最小元件尺寸，后面整套配置都要返工。

---

## 触发场景

- 客户视频会议结束，需要整理纪要
- 拿到会议录音/转写文本，要提炼行动项
- 展会现场洽谈，需要快速记录并转跟进
- 内部复盘会，要沉淀决策与责任人

---

## SM 硬约束

- 术语保留英文：Pick-and-place、Reflow、Wave Soldering、CPH、Gerber、BGA、Pitch、Feeder、Nozzle、Conveyor
- 契约数据（PCB 尺寸与最小元件 / 目标 CPH / 线体兼容性）只要会议中出现，**必须单独成段记录**，这是方案输入
- 涉及价格的承诺：只能记"已提供预算区间"，**不得记录为已确认最终价格**
- 整线连带检查：会议中若提到 S-70LD 或 S-WS450，检查配套（STF1003 / SUL460）是否被提及

## 工作流

### Step 1：区分四类信息

从转写或笔记里逐条归类：

| 类别 | 内容 | 用途 |
|---|---|---|
| **事实** | 客户产线现状、产能、设备品牌、产品规格 | 方案输入 |
| **承诺** | 我们答应给的（资料、报价、日期）、客户答应给的（Gerber、决策时间） | 跟进依据 |
| **异议** | 客户提出的顾虑（价格、交期、售后、品牌） | 需单独处理 |
| **待确认** | 双方都没结论、需内部核实的事 | 内部任务 |

**判断标准**：这条信息会不会影响后续动作？不会 → 不写进纪要。

### Step 2：契约数据专项提取

只要会议里出现以下任一项，单独成段：

```
【契约数据】
- PCB 尺寸范围：[值 / 未提及]
- 是否双面贴装：[是/否/未提及]
- 最小元件尺寸：[0201 / 01005 / 0.4mm pitch BGA / 未提及]
- 目标产能：[CPH 或月产量 / 未提及]
- 现有线体品牌与 Feeder 型号：[Yamaha / JUKI / Panasonic / 无 / 未提及]
- 产品类型：[汽车电子 / 医疗 / 消费 / 工控 / 未提及]
- 采购时间窗：[值 / 未提及]
- 决策人与角色：[姓名职位 / 未提及]
```

**未提及的项也要列出来标"未提及"**——提醒下次会议要问。

### Step 3：承诺项双向登记

```
【我方承诺】
| 内容 | 负责人 | 承诺时间 | 状态 |
|---|---|---|---|
| 发送 S-70LD 配置清单 | Jason | 8-30 | 待办 |

【客户承诺】
| 内容 | 对接人 | 期望时间 | 跟进方式 |
|---|---|---|---|
| 提供 Gerber 文件 | Mr. X (工艺) | 下周 | 9-02 邮件提醒 |
```

**规则**：每条承诺必须有责任人和时间。没有的，在纪要里标注"待定"，不要默默略过。

### Step 4：异议单独处理

客户提出的每个顾虑，都要给出处理方向，不能只记录：

| 异议类型 | 记录方式 |
|---|---|
| 价格 | 记录客户参照对象（二手 JUKI？本地代理？）+ 我们的价值锚定方向 |
| 交期 | 记录客户期望时间 + 需内部核实的排产情况 |
| 售后 | 记录客户所在地 + 我们可提供的支持方式（远程/现场/备件） |
| 品牌信任 | 记录客户对中系设备的具体疑虑 + 可提供的佐证（案例、认证、验厂） |
| 兼容性 | 记录客户现有品牌型号 + 需技术部确认的接口问题 |

### Step 5：生成跟进邮件

纪要完成后直接产出跟进邮件（英文，乙商务档）：

```
结构：
1. 感谢 + 一句证明我们听懂了他的产线（引用会议里的具体细节）
2. 本次会议确认的关键点（3–5 条，bullet）
3. 我方承诺清单（带时间）
4. 客户需提供清单（带原因）
5. 下一步时间点
```

**禁止**：`Just following up`、`As discussed in the meeting` 这类无信息量开头；不要把客户没说的话写进去。

### Step 6：CRM 录入字段

给出可直接录入 Worktile / 小满 CRM 的字段：

```
客户名称 / 国家 / 联系人与职位
询盘来源 / 当前分层（L0–L4，见 smthelp-inquiry-followup）
需求机型 / 工艺方向
契约数据完备度：[已获取项数]/8 —— 八项为：PCB尺寸范围、是否双面贴装、
    最小元件尺寸、目标产能、现有线体品牌与Feeder型号、产品类型、
    采购时间窗、决策人与角色。"未提及"不计入已获取。
下一步动作 / 时间点
预计金额区间（仅预算区间，非最终价）
```

```text

  客户：[公司] / [国家]

  时间 / 形式：[视频 / 展会 / 到访]
  语言：[中/英]

一、客户现状（事实）
  - …

二、契约数据
  [八项清单，未提及的显式标注]

三、我方承诺
  [表格：内容 | 负责人 | 时间]

四、客户承诺
  [表格：内容 | 对接人 | 期望时间 | 跟进方式]

[英文正文]

---
【CRM 录入】
[字段表]
```

## Gotchas

1. **不要写成流水账**
   解释："客户问了价格，我们说要问需求"这种记录没有价值。要记的是**结论**：客户的目标 CPH 是多少、我们还缺什么、谁去补。

2. **不要漏记技术参数**
   解释：会议里随口提到的"我们最小做到 0201"就是方案的关键输入。漏了会导致后续重新问一遍，客户会觉得我们不认真。

3. **不要把价格讨论记成承诺**
   解释：会上说的区间是预算区间，不是报价。纪要里写"已提供预算区间 USD X–Y（取决于工艺选配）"，不要写"报价 X–Y"。

4. **不要只记我方承诺**
   解释：客户答应给 Gerber、答应安排决策人参会，这些同样要登记并跟进，否则会议永远停在"等客户"。

5. **不要在跟进邮件里写客户没说过的话**
   解释：为让纪要好看而补充客户没确认的需求，会在后续方案中造成严重误解。不确定就写"待确认"。

6. **不要跳过"未提及"的标注**
   解释：契约数据清单里没提到的项，显式标"未提及"，下次会议才有明确的提问目标。留空等于假装问过了。

7. **不要把内部成本与底价写进纪要**
   解释：纪要是会被转发和归档的文档。内部毛利、底价、对客户的评价，另存内部文件。
