# SMT 设备短视频脚本

## 核心定位

工业设备的短视频和消费品完全不同。观众不是来被娱乐的，是来**确认这台机器真的能干这件事**的。

所以第一原则是：**前 3 秒必须是机器在跑的画面**。Logo 动画、公司大门、PPT 封面、会议空镜，都会让人划走。

第二原则：**参数上屏比口播更有说服力**。海外工程师可能听不懂口音，但看得懂 `0.8 s/件` 和一组连续下板的画面。

---

## 触发场景

- "给 S-70LD 写个 60 秒视频脚本"
- "展会大屏要一个循环播放的短片"
- "把这个客户案例拍成视频"
- "LinkedIn 上发一段机器运行视频，配什么文案"

## SM 硬约束

- 品牌色：Primary Green `#90C641`（参数字幕、进度条）、Primary Teal `#0AA5A5`（标题条、边框）
- 术语上屏用英文：Pick-and-place、Wave Soldering、Odd-form Insertion、CPH、Feeder、Unloader
- 整线连带：拍 S-70LD 要带到 STF1003 供料；拍 S-WS450 要带到 SUL460 下板
- 参数上屏前必须经技术部确认；**不确定的数字不上屏**
- **上屏数字必须能在 `smthelp-brand-voice/references/smt-term-bank.md` 第二节查到**，
  并**带机型**（`±0.05 mm` 必须写成 `S-7900 · ±0.05 mm`）。
  已知**不在**确认清单、禁止上屏的：S-WS450 链速（m/min）
- 结尾 CTA 用画面 + 文字，不要用报价

## 工作流

### Step 1：确定视频类型

| 类型 | 时长 | 目的 | 主画面 |
|---|---|---|---|
| **运行实况** | 30–45 秒 | 证明机器能跑、跑得稳 | 连续运行特写 |
| **机型介绍** | 60–90 秒 | 说清解决什么问题 | 工况 + 参数 + 配套 |
| **改造对比** | 45–60 秒 | 算账说服 | 人工工位 vs 自动工位 |
| **客户案例** | 60–90 秒 | 建立信任 | 客户现场（需授权） |
| **展会循环** | 30 秒，无字幕依赖 | 抓住走过的人 | 快切运行画面 + 大字数字 |

先定类型，再定结构。

### Step 2：写钩子（前 3 秒）

**可用钩子：**

| 钩子 | 画面 | 字幕 |
|---|---|---|
| 数字冲击 | 机器连续下板 | `0.8 s / point` |
| 人工对比 | 工人手工插件 | `2 operators per shift` |
| 反常识 | 板子在出口堆住 | `Your bottleneck is here` |
| 结果前置 | 成品板堆叠 | `10 odd-form parts. 8 seconds.` |

**禁止**：Logo 动画开场、公司大门、航拍厂区、"欢迎来到 Southern Machinery"、PPT 封面静止 3 秒。

### Step 3：分镜结构

#### 30–45 秒 运行实况
```
0–3s    机器运行特写（必须有运动）+ 关键数字上屏
3–15s   核心工位特写（吸嘴动作 / 板子传送 / 焊接波峰）
15–30s  连续运行，展示稳定性与一致性
30–40s  配套件入镜（STF1003 / SUL460）
40–45s  CTA：文字 + 网站
```

#### 60–90 秒 机型介绍
```
0–3s    钩子画面 + 数字
3–10s   痛点场景（人工插件 / 出口堆料）
10–25s  机器解决这个问题的画面 + 参数上屏
25–45s  配套与整线关系（为什么不是单独一台）
45–65s  稳定运行的长镜头
65–80s  价值锚定：源头工厂 + 全球服务（各一个画面）
80–90s  CTA：发送 Gerber / 预约视频验厂
```

#### 45–60 秒 改造对比
```
0–3s    人工工位画面 + 人数
3–15s   人工段的问题（节拍慢、一致性差）
15–30s  自动段同工序画面 + 时间对比
30–45s  算账：节省人数 → 回本周期（数字上屏）
45–60s  CTA
```

### Step 4：写口播稿

**规则：**
- 每句 ≤ 15 个词，口语化
- 参数在口播里说一次，同时上屏（听觉 + 视觉双通道）
- 不要念参数表
- 不要说"我们的产品采用先进技术"这类空话

```
示例（S-70LD）：
"Ten odd-form components. One operator. About fifteen seconds."
[画面：人工插件]
"At 0.8 seconds per feed, the S-70LD puts those ten in eight — and it doesn't
need a break."
[画面：机器运行, 字幕 S-70LD · STF1003 · 0.8 s/件]
"It ships with the STF1003 tube feeder, so it doesn't stop for material."
[画面：供料器特写]
"Send us your Gerber file. We'll run the numbers on your board."
[画面：CTA 文字]
```

> 上例的 `eight seconds` 是**推算值**，不是设备参数：
> `10 件 × 0.8 s/件（STF1003 实测）= 8 s`。
> 推算链必须在脚本备注里写明，**并注明"理论节拍，不含上下料"**。
> 推算值和实测值要区分——实测值写 `实测`，推算值写 `理论节拍`。
> 反过来，S-WS450 的链速**不能这样推**，因为基础参数本身就不在确认清单内。

### Step 5：参数上屏规范

| 项目 | 写法 | 来源 |
|---|---|---|
| 供料节拍 | `0.8 s/件`，不要写 `fast` | STF1003 |
| 产能 | `4,000 CPH`（S-7900）/ `12,000 CPH`（S-7020T）/ `10,000–12,000 CPH`（S-3000）**带机型** | term-bank |
| 精度 | `±0.05 mm`（S-7900）/ `±0.015 mm`（S-7020T）**带机型，不可串用** | term-bank |
| 尺寸 | `50 × 50 – 400 × 400 mm`（S-3000 PCB 范围） | S-3000 |
| 温度 | `280 °C preheat / 300 °C solder`（S-WS450） | S-WS450 |
| 节拍 | `≈30 s magazine change`（SUL460） | SUL460 |
| 颜色 | 参数用 `#90C641`，标题条用 `#0AA5A5` | 品牌规范 |
| 时长 | 每个数字上屏 ≥ 2 秒，让人看得完 | — |

> **禁止上屏**：S-WS450 链速（m/min）、任何未标注机型的裸数字、
> 任何 term-bank 里查不到的参数。宁可少一个数字，不可错一个数字。

### Step 6：列出待拍素材清单

脚本必须附素材清单，标明哪些已有、哪些要拍：

```
待拍素材：
- [ ] S-70LD 连续插件特写（侧机位，30 秒长镜头）
- [ ] STF1003 供料动作特写
- [ ] 成品板堆叠画面
已有素材：
- [x] 厂区空镜
```

## Gotchas

1. **不要用 Logo 动画开场**
   解释：这是工业设备视频最高频的错误。观众刷到视频只给 2 秒判断要不要看，Logo 动画等于放弃这 2 秒。第一个画面必须是机器在动。

2. **不要念参数表**
   解释：60 秒视频念不完参数，念了也没人记。选 1–2 个最关键的数字上屏 + 口播一次，其余放描述区。

3. **不要上屏未经确认的数字**
   解释：视频是被截图和转发最多的载体，一个错误参数会被永久传播。不确定的数字宁可不上屏，改用画面表达。

4. **不要拍单机不带配套**
   解释：S-70LD 单独拍会让人以为缺料停机是常态。必须带到 STF1003，这是我们的整线差异化。

5. **不要用报价做 CTA**
   解释：视频是公开渠道，写价格会被不同市场的客户看到，也会给竞品递刀。CTA 用"发 Gerber / 预约视频验厂"。

6. **不要忽略展会循环播放的特殊性**
   解释：展会现场声音嘈杂，观众走过就一眼。这类视频必须**无口播依赖**——全靠大字数字和画面，且短（≤ 30 秒）。

7. **不要用客户现场画面而未获授权**
   解释：拍客户产线涉及保密协议。需要授权才能用于公开渠道，否则只能内部使用或做脱敏处理。
