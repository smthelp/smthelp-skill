# B2B 产品文案（SMT 设备）

## 核心定位

消费品的商单文案解决"让用户在内容里自然接受一个产品"，B2B 工业设备解决的完全是另一件事：**让一个要对产线负责的工程师，在 30 秒内判断出这台设备跟他的问题有关，并愿意再花 3 分钟要资料。**

所以这里没有"软植入"的概念。B2B 读者带着问题来找答案，藏产品名只会让他关掉页面。核心是**把卖点翻译成他产线上的具体结果**。

---

## 触发场景

- "给 S-70LD 写一段产品文案 / 落地页"
- "写一条 LinkedIn 帖子推这个机型"
- "写展会物料的主标题和卖点"
- "更新 Alibaba / Made-in-China 的产品描述"
- "写一封推新机型的开发信"

---

## SM 硬约束

- 术语保留英文，首次出现可加中文注释
- 禁用绝对化用语：最好 / 第一 / 顶级 / 唯一 / 根治
- 报价熔断：文案中不出现最终价格；可给预算区间并注明取决于工艺选配
- 整线连带：S-70LD → STF1003；S-WS450 → SUL460
- 价值锚定三件套：深圳源头工厂（2011）+ 全球售后（24–48 h）+ ROI 换算（2–3 年回本）
- 落地页 / 报价类输出结尾带强制 CTA 两行（见 `smthelp-brand-voice`）
- **参数可溯源**：每个数字必须能在 `smthelp-brand-voice/references/smt-term-bank.md`
  第二节查到。查不到的一律不写，改为"待技术部确认"并列入输出末尾的待确认清单

## Step 1：把卖点翻译成产线结果

这是整个 skill 最关键的一步。品牌语言和用户语言的对照：

| 品牌语言 | 产线结果（用户语言） | 参数来源 |
|---|---|---|
| 高速异形插件 | STF1003 管装供料 0.8 s/件节拍，替代人工插件工位；不再因为招不到人卡产能 | STF1003 实测 |
| 高精度（S-7900） | ±0.05 mm 重复定位精度，Active Clinching 主动折弯，汽车电子 / BMS 焊点可靠 | S-7900 |
| 高精度（S-7020T） | ±0.015 mm，12,000 CPH，端子 / 继电器座插入 | S-7020T |
| 稳定可靠 | 缺陷率 <500 PPM（工厂验证）；STF1003 弹簧寿命 400 万次，48 h 老化 + 连续供料 1000 次无异常 | S-3000 / STF1003 |
| 维护成本 | 兼容 Universal 备件，月均备件成本 <$100 | S-3000 |
| 智能供料 | 物料 3×3×3 – 25×25×25 mm，料管 200–650 mm 通用，四档调速，缺料不停机 | STF1003 |
| 整线方案 | S-70LD + STF1003 打包，THT 段不用再单独找配套 | 配套规则 |
| 全球服务 | 远程诊断 + 现场支持，**24–48 小时**响应 | 商务锚点 |

**规则**：每一条卖点必须能回答"所以客户的哪件事变好了"，且**参数能在
`smthelp-brand-voice/references/smt-term-bank.md` 第二节查到**。答不上来或查不到的卖点删掉。

> ⚠️ **易错点**：`0.4 mm pitch BGA` 是 **SMT 贴片机**的指标，不是 THT 插件机的。
> 写 S-70LD / S-7900 文案时不要用它做精度佐证，用上表对应的机型精度。
> 同理，**S-WS450 的链速（m/min）不在已确认清单内**，不要凭印象填数字。

## Step 2：选主角度

| 角度 | 适用 | 结构 | 风险 |
|---|---|---|---|
| **痛点-算账型** | 客户明确知道痛在哪（人工、返修、产能） | 现状成本 → 算账 → 改造后 → 回本周期 | 数据必须真实 |
| **对比选型型** | 客户在几个方案之间犹豫 | 选型维度表 → 各方案对比 → 什么情况选我们 | 不能贬损竞品品牌 |
| **工艺原理型** | 客户是工程师，想搞懂机理 | 原理 → 参数 → 为什么这个参数重要 | 需要真懂，不能喊概念 |
| **应用场景型** | 新品推广、开拓新行业 | 典型工况 → 配置 → 客户得到的产出 | 场景要具体到板子和产量 |
| **案例实证型** | 有真实交付案例 | 客户处境 → 方案 → 改动 → 可核对的结果 | 需客户授权，数据可核 |

一次只选一个主角度，辅以最多一个次角度。**卖点不超过 3 条**，多了记不住。

## Step 3：按渠道组装

### LinkedIn 帖子（100–200 词）
```
第 1 句：一个反常识判断或一个现场问题（不要打招呼）
第 2–4 句：展开，给出具体工况或数字
第 5–6 句：我们的做法/机型，只说一个点
最后 1 句：一个问题（不要 CTA 链接，评论里发）
```
规则：无 emoji；参数放评论区；不要在正文贴产品目录。

### 产品落地页
```
主标题：[机型] + [核心工艺] + [关键结果]
  例：S-70LD Odd-form Insertion — 3–25 mm components at 0.8 s per feed, STF1003 included
  例：S-7900 — 4 heads, ±0.05 mm, Active Clinching for automotive-grade joints

副标题：给谁用、解决什么

3 个卖点块（每块：结果句 + 支撑参数 + 配套说明）

参数表（表格，不加粗滥用）

适用 / 不适用 场景（这段最建立信任）

价值锚定：深圳源头工厂 + 全球售后 + ROI 示例

强制 CTA 两行 + 资料下载按钮
```

### 开发信（80–150 词）
```
第 1 句：他产线上的一个具体问题（证明你懂，不是群发）
第 2 句：我们怎么处理这个问题（一个点，不要罗列）
第 3 句：一个可核对的数字或案例
第 4 句：一个低门槛动作（发 Gerber / 看 30 秒视频）
```
规则：**不要** Dear Sir/Madam；**不要** 贴价目表；**不要** 介绍公司历史。

### 展会物料
```
主标（≤ 12 词）：工艺 + 结果
3 个卖点（每条 ≤ 8 词）
1 个二维码（视频或配置清单）
```
规则：30 秒扫一眼要能记住一件事。不要放参数表。

### Alibaba / Made-in-China 列表
```
标题：[机型] + 核心工艺 + 关键参数 + 应用场景（填满关键词位）
属性表：全部填完（空字段严重影响搜索权重）
正文：应用场景 → 参数表 → 配套 → 包装与交期 → 服务
```
规则：交期写区间（如 30–45 days），不承诺固定日期；认证按实际填写。

## Gotchas

1. **不要用消费品那套"软植入"**
   解释：B2B 读者是带着问题来的，藏产品名只会让他以为点错了页面。产品应该在前 30 秒出现。

2. **不要把品牌方给的 USP 直接当文案**
   解释："高效智能"不是文案，是内部话术。必须翻译成产线结果——省几个人、少多少返修、节拍降多少。

3. **不要堆卖点**
   解释：一次给 6 个卖点等于一个都没给。选最重要的 1–3 条，其余放进参数表让需要的人自己看。

4. **不要承诺具体交期或认证**
   解释：交期取决于配置与排产，认证取决于目标市场。写区间并注明"配置确认后提供确切 lead time"。

5. **不要贬损竞品品牌**
   解释：可以对比参数、成本、交期、服务响应，不能说"我们比 Yamaha 好"。海外工程师对品牌有感情，贬损会立刻失去 credibility。

6. **不要用无法核对的数字**
   解释："客户遍布 100 多个国家"如果没有可核对依据，就换成"服务于汽车电子、医疗电子、工控等领域的 EMS 工厂"。宁可模糊，不可虚构。
