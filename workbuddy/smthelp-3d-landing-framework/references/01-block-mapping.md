# 01 · 原框架 → B2B 工业版：映射与改造原理

## 源头

Azou《DeepSeek Harness 工具包》第 5 节 — "3D Creator-style portfolio landing page" Prompt Spec。

原框架：深色 `#0C0C0C` + Kanit 巨型标题 + Magnet 磁吸抽象 3D 肖像 + 21 张 motionsites 抽象动效 GIF 双向跑马灯 + 字符级渐显文案 + 白底编号列表 + 深色粘性叠卡。服务对象：**个人 IP 作品集**。

> **抓取提示**：WebFetch 抓 Google Doc 只拿到登录墙。必须用
> `curl -sL "https://docs.google.com/document/d/<ID>/export?format=txt"` 才能拿到正文。

## 为什么不能直接套用

原框架的所有设计决策都服务于一个目标：**让人觉得这个人很酷**。
B2B 工业设备页的目标相反：**让一个要对产线负责的工程师，判断出这家公司懂他的工艺**。

两者对"3D"的态度是冲突的：
- 个人作品集里，抽象 3D 是**审美信号**
- 设备页里，抽象 3D 是**信任成本**——工程师会问"为什么不给我看机器"

所以改造不是"换个配色"，是**把视觉证据的类型整体替换**。

## 映射表

| 原框架要素 | 原作用 | 改造后 | 为什么 |
|---|---|---|---|
| 抽象 3D 肖像 + Magnet | 人格化、抓眼球 | **设备主视觉**（3/4 视角去背渲染/实拍）+ Magnet + **Hotspot 参数标注点** | 工程师要看到机器本体；抽象 3D 卡通形象摧毁专业信任 |
| 21 张 motionsites 抽象动效 GIF | 视觉炫技 | **6–12 条真实设备动作素材**（焊点特写 / 出板 / 喷雾 / 预热区 / 下板 / HMI） | 前 3 秒必须是**机器在动** |
| 滚动系数 `0.3` | 位移灵敏度 | **`0.25`** | 工业实拍比抽象图更容易晃眼，速度必须更慢 |
| About 区字符级渐显长段落 | 叙事节奏 | 字符渐显只用于 **2–3 句工艺原理**；**参数严禁逐字动画** | 参数必须一次性可读、可截图、可转发 |
| Tracks 白底编号列表（5 条服务） | 能力模块 | **Specs 编号参数墙** + 单位 + 溯源标注 | 采购第一动作是扫参数 |
| Projects 深色粘性叠卡（3 个作品） | 作品集 | **Application 叠卡**（垂直行业工况） | 结构同构，直接复用 |
| 深↔浅圆角分段容器 | 视觉节奏 | 保留，语义化为 **深色=品牌/技术叙事，浅色=硬参数/FAQ** | 深浅交替 = 内容节奏 |
| JoinButton 紫橙渐变 `#B600A8→#BE4C00` | CTA 视觉锤 | **Teal→Green 品牌渐变**，文案 `Request a Quote` | 紫色不属于工业 B2B 语境 |
| 无信任区 / FAQ / 合规 | 个人站不需要 | **新增 Trust/ROI/报价熔断/FAQ/强制 CTA** | B2B 采购决策必须有信任证据与风险边界 |

## 保留的三个"骨架机制"

这些是原框架真正有价值的部分，改造后原样保留：

1. **深↔浅圆角分段容器**
   每个区块用 `rounded-t-[40/50/60px]` 的大圆角切分，深色段用 `-mt-10 sm:-mt-12 md:-mt-14` 上提压住上一段。
   作用：给读者一个无意识的"阶段切换"信号。
   本框架语义化：深色段 = 品牌与技术叙事，浅色段 = 硬参数与 FAQ。

2. **滚动驱动的双向跑马灯**
   两行反向位移，位移量由 `scrollY` 计算。
   作用：把"滚动"这个必须发生的动作变成内容的一部分。
   本框架只改了两处：素材换成真实设备影像，系数 0.3 → 0.25。

3. **字符级渐显（AnimatedText）**
   逐字符 opacity 0.2 → 1，由 `useScroll` 驱动。
   作用：强制读者按你的节奏读。
   本框架限制使用范围：**只能用于 2–3 句的工艺叙事，参数区禁用**。
   理由：参数需要被截图、被转发给同事，逐字动画会破坏可读性。

## 新增的六个 B2B 区块

原框架完全没有，本框架补齐：

| 区块 | 作用 |
|---|---|
| **TrustStrip** | CE / Since 2011 Shenzhen / 24–48h remote diagnostics / Global field service |
| **ROI Block** | CapEx vs 日系 30–50%、回本 2–3 年、服务响应 24–48 h |
| **报价熔断条** | 三问拿契约数据：PCB 尺寸 / 目标产能 / 现有线体品牌与 feeder 型号 |
| **FAQ Accordion** | 兼容性、交期、CE 文件、备件、调试培训、报价所需资料 |
| **Quote Form + Footer** | 询盘表单 + 强制 CTA + 全渠道联系方式 |
| **移动端 sticky 底栏** | WhatsApp 常驻（海外买家主要用 WhatsApp / LinkedIn 内置浏览器） |

## 一句话总结

> 3D 感来自**空间排版与材质**（深色舞台、大圆角、设备悬浮、滚动视差），
> **不来自 3D 素材本身**。设备影像必须真实。
