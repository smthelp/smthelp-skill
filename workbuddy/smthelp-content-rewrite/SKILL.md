# 改稿（SMT 外贸版）

## 核心定位

改稿不是同义词替换，而是**理解参考内容为什么有效，然后用我们的素材和立场重新实现同样的有效性**。

合格标准：结构可学，逻辑可用，但表达、案例、数据全部替换；任意 15 个连续字与原文不重合。

---

## 触发场景

- "参考竞品这篇，帮我写一个我们的版本"
- "把这篇旧文章翻新一下"
- "这个同题材内容很好，我要一个不雷同的版本"
- "拆解一下竞品的落地页，改成我们的说法"

**优先使用竞品来源**：Yamaha、JUKI、Panasonic、ASM、Fuji、ERSA、SEHO 的公开技术资料与落地页，是最值得改写的素材库。

---

## SM 硬约束

- 术语保留英文，改写时不要顺手翻成中文
- 改写后的**参数必须替换成我们的真实数据**；拿不到就标"待补"，**绝不沿用竞品数字**
- 删掉竞品的品牌名、型号、专利名、客户名
- 保留整线连带（S-70LD + STF1003、S-WS450 + SUL460）
- 禁用绝对化用语

## 工作流

### Step 1：解构参考内容

**1.1 核心主张** — 一句话概括它想让客户相信什么。

**1.2 逻辑骨架**
```
论点1 → 证据类型（参数/案例/对比/权威） → 小结论
论点2 → 证据类型 → 小结论
总结论 → 行动召唤
```

**1.3 有效性诊断**（找出 1–2 个主要因素）

| 因素 | 是否主因 |
|---|---|
| 具体工况代入（写出了读者产线上的真实场景） | |
| 数字冲击（意外的参数或算账结果） | |
| 反常识（颠覆主流选型思路） | |
| 算账说服（把成本摊到人头/月份） | |
| 实用价值（直接可操作的选型方法） | |
| 身份认同（说出了工艺工程师想说没说的话） | |

**1.4 语言风格** — 句长 / 人称 / 语气 / 3–5 个标志性句式。

### Step 2：划清改写边界

**可以保留（结构层）**
- 逻辑推进关系与段落功能分工
- 使它有效的核心机制（若原文靠"算账"说服，保留算账框架）
- 信息呈现顺序（先问题后方案，或先结论后论证）

**必须替换（表达层，零容忍）**
- 所有句子表达
- 所有案例、机型、参数、客户名
- 所有比喻与类比
- 标题与所有小标题
- 开头与结尾
- 数据来源

**硬标准**：任意 15 个连续字不与原文重合。

### Step 3：设定目标声音

```
文体档位：甲正式 / 乙商务 / 丙内容 / 丁内部（见 smthelp-chinese-polish）
目标声音：销售工程师 / 工艺专家 / 观察者
语气：冷静客观 / 犀利直接 / 务实
人称：我 / 我们 / 第三人称
```

若用户提供范本，提取其 3–5 个标志性句式作为参照。

### Step 4：分块改写

每块完成后检查：核心论点保留了？表达 100% 是新的？案例替换了？参数换成我们的了？

**四种核心技术：**

1. **换案例** — 竞品用 A 客户举例 → 换成我们的真实交付案例，或换成一块具体板子的工况推演。找不到对等案例时，改用**算账**替代案例（更稳妥）。

2. **换参数** — 竞品的所有数字必须替换。我们的数字拿不到时，改成"以技术规格书为准"或标"待补"，**不要沿用、不要估算**。

3. **换论证方式** — 原文靠权威背书 → 改成靠工况推演；原文靠数据 → 改成靠逻辑。

4. **换开头** — 原文用故事开头，我们就用数字；原文用问题，我们就用反常识陈述。

### Step 5：全文质检

- **查重**：改写稿与原文各取 5 段并排，逐句比对。重点查过渡句、列举句、总结句（这三处最容易无意识保留原文结构）。
- **有效性**：原文让人想读下去的核心张力还在吗？
- **合规**：竞品品牌名、型号、客户名是否清干净？参数是否都换成了我们的？

## 输出格式

### 改写前先出方案

```
【参考内容解构】
来源：[竞品/同行/自家旧文] + [出处]
核心主张：[一句话]
逻辑骨架：[论点 → 证据 → 结论，逐条]
有效核心因素：[1–2 个]
原文风格：[简述]

【改写方案】
目标文体档位：[甲乙丙丁]
结构调整：[保留原结构 / 如何调整]
案例替换计划：
  - 原文 [描述] → 替换为 [方向]
参数替换计划：
  - 原文 [数字] → [我们的数字 / 待补]
开头策略：[与原文不同的钩子类型]

确认后开始改写。
```

### 改写稿

完整正文，末尾附：

```
【改写说明】
结构保留：[保留了什么逻辑，为什么保留]
主要改变：[表达、案例、参数的改变方向]
案例/参数对照：逐条列出 `[原文写法] → [改写写法]`，
    参数类改动必须注明机型与出处，如
    `0.8 s/点（无机型）→ STF1003 供料 0.8 s/件（term-bank 供料系统）`
待补数据：[列出需要技术部确认的数字，空则写"无"]
```

## Gotchas

1. **同义词替换不是改稿**
   解释："提升生产效率"改成"提高制造效能"毫无意义。真正的改写是把"我们的设备很稳定"改写成"这台机器在客户产线上连续跑了 X 小时没调机"——用具体替换抽象。

2. **最容易翻车的位置是参数**
   解释：改写竞品内容时，参数是最容易被无意识沿用、也是最致命的部分——用了竞品的参数等于替竞品做广告，且暴露我们没有真实数据。**每个数字都要过一遍。**

3. **结论段最容易被忘掉**
   解释：大量改写者改到结尾直接沿用原文总结。结论段必须重写，且要带上我们的立场。

4. **不要改写竞品的独家内容**
   解释：竞品的原创研究数据、独家访谈、专利结构描述，只能参考其**论证思路**，不能改写内容。

5. **不要为了不重复而用生僻词**
   解释：该换的是表达方式，不是词汇难度。技术文案里出现生僻词会立刻显得不专业。

6. **不要保留竞品的品牌名做对比**
   解释：即使"客观对比"也不建议署名对比。改写成"常规做法 vs 我们的做法"，风险更低。
