# 竞品与客户情报采集

## 核心定位

原版内容抓取面向小红书、微博、知乎这类中文社媒，对 SMT 设备外贸几乎没有用。本版把同一套方法（识别来源 → 处理登录墙与截断 → 结构化提取 → 限流）搬到 B2B 工业场景。

三类用途：
1. **竞品监测** — 机型参数、价格信号、新品、渠道动作
2. **客户背景调查** — 收到询盘后核实这家工厂的真实规模与工艺
3. **定价参考** — 同类设备在各市场的公开报价区间

依赖 browser 能力作为底层执行引擎。

---

## 触发场景

- "查一下 [竞品] 这款机型的公开参数"
- "核实一下这家询盘客户的背景"
- "看看同行在 [市场/平台] 怎么挂产品和报价"
- "展会前扫一遍参展商名单"
- 定期竞品动态监测

## 工作流

### Step 1：来源识别与策略选择

| 来源类型 | 代表 | 可获取信息 | 注意 |
|---|---|---|---|
| 竞品官网 | Yamaha、JUKI、Panasonic、ASM、Fuji、ERSA、SEHO | 机型参数、配置、白皮书 | 参数表常折叠，需展开 |
| B2B 平台 | Alibaba、Made-in-China、GlobalSources | 同行报价区间、标题关键词、属性字段 | 列表页价格常为区间或"面议" |
| LinkedIn | 竞品公司页、目标客户员工 | 组织规模、人员构成、动态 | 未登录只能看有限内容 |
| YouTube | 竞品频道、行业展会视频 | 机型运行实况、客户现场 | 视频内容需另做转写 |
| 展会商名录 | productronica、NEPCON、IPC APEX EXPO、SMTAI | 参展商名单与主营方向 | 名录常为 PDF 或分页 |
| 进口/海关数据 | ImportGenius、Panjiva、Volza | 客户实际采购记录与供应商 | 需付费账号 |

**先判断这条信息是否真的能拿到。** 拿不到就明确说"未获取到"，不要用相似内容凑数。

### Step 2：处理访问障碍

**登录墙**（LinkedIn 最常见）
```
检测到 "Sign in" / "Log in" / "Join now" → 提示用户在已打开的浏览器完成登录 → 确认后重新加载
```
不要尝试绕过验证码，不要使用代理池高频请求。

**内容截断**

| 平台 | 表现 | 处理 |
|---|---|---|
| 竞品官网参数表 | "Show more" / 折叠面板 | 逐层 click 展开后再提取 |
| Alibaba 列表 | 详情页描述折叠 | click "View more" |
| LinkedIn 帖子 | "…see more" | click 展开 |
| 展会名录 | 分页 | 逐页翻，记录页码上限 |

**禁止**：绕过验证码、使用代理池模拟高频请求、抓取登录后才能访问的付费数据并外传。

### Step 3：结构化提取

#### 竞品机型
```
品牌 / 型号 / 工艺类型
关键参数：速度（CPH 或 s/point）、精度、PCB 尺寸范围、元件范围
配套件：feeder 类型、是否含 loader/unloader
公开价格信号：区间 / "面议" / 无
资料链接：规格书 PDF、视频
更新日期（能看到的话）
```

#### 客户背景核实
```
公司全称与所在国
工厂规模信号：员工数（LinkedIn）、厂房面积、产线数量
工艺方向：SMT / THT / 混装
终端行业：汽车电子 / 医疗 / 消费 / 工控
决策人：采购 / 工艺 / 运营，姓名与职位
近期动态：扩产、搬迁、新品、招聘（招工艺工程师通常意味着扩线）
红旗信号：无官网、LinkedIn 无员工、地址为虚拟办公室、公司注册时间极短
```

#### 平台同行定价
```
同行名称 / 机型 / 标题写法
价格区间（含 MOQ 与贸易条款）
属性字段完整度（影响搜索权重，也是我们的改进点）
主图风格与数量
```

### Step 4：限流与节奏

```
每次页面操作后随机等待 1–2 秒
批量抓取：每 10 个 URL 暂停 30 秒
检测到 "Too many requests" / 验证码：暂停 5 分钟后继续，或终止并报告
```

### Step 5：校验与标注

- 参数必须记录**来源 URL 与页面日期**
- 无法确认的字段写 `null` 并在 `warnings` 说明原因，不要留空让人以为遗漏
- 相对时间（"3 天前"）记录原始文本 + 抓取时间，不做转换
- 竞品参数与我们的机型做对比时，明确标注工况差异（不同测试条件下 CPH 不可直接比）

## 输出格式

```json
{
  "task": "竞品参数 / 客户背景 / 平台定价 / 展会名录",
  "target": "目标公司或机型",
  "scraped_at": "2026-08-28T10:30:00+08:00",
  "sources": [
    {"url": "https://...", "type": "竞品官网", "accessed": "2026-08-28", "page_date": "2026-05-12 或 null"}
  ],
  "findings": {
    "key_parameters": {},
    "signals": [],
    "red_flags": []
  },
  "comparison_with_us": "与 S-70LD / S-WS450 的可比点与不可比点（注明工况差异）",
  "warnings": ["需要登录才能查看完整内容", "价格显示为面议"],
  "confidence": "高 / 中 / 低 —— 依据"
}
```

人类可读版本：先给一段结论（这家客户/这款竞品的关键判断），再给数据表。

## Gotchas

1. **不要把不同工况下的 CPH 直接对比**
   解释：竞商标称 CPH 往往基于 IPC9850 或自有测试板，与我们的测试条件不同。直接比数字会得出错误结论，也会在客户面前被戳穿。对比必须注明工况。

2. **不要抓取并留存登录后的付费数据**
   解释：海关数据平台等付费源的抓取涉及服务条款与合规风险。需要时走正规采购或人工查证。

3. **不要把平台挂牌价当成成交价**
   解释：Alibaba 上的价格多为引流区间，与实际成交差距很大。只能作为价格带参考，不能作为定价依据。

4. **不要绕过验证码或用代理池**
   解释：工业 B2B 的调研量不需要这种强度，风险与收益完全不匹配。触发风控就暂停并报告。

5. **不要凭 LinkedIn 员工数判断工厂规模**
   解释：很多工厂的员工不用 LinkedIn。要交叉验证（官网、厂房照片、招聘信息、海关记录）。单一来源得出的结论要标注低置信度。

6. **不要忘记记录页面日期**
   解释：竞品参数会更新，三个月前抓取的规格书可能已改版。没有日期的情报无法用于决策。

7. **不要把查不到当成没有**
   解释：竞品官网没写某个参数，可能是没公开，也可能是我们没有找到正确的规格书页面。写"未获取到"并说明检索路径，不要写"该机型无此参数"。
