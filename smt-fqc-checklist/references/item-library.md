# 通用条目库与建议值 / Item library & suggested values

G 编号是**建议值**：资料未给出时可引用，item 必须 status S、显示 ★、进入问题清单，Jason 确认后才可转 C。产品资料的数值永远优先。新增条目按分类追加编号，不复用旧编号。

| 编号 | 条目 | 建议判定 | 方法 / 工具 |
|---|---|---|---|
| G-APP-01 | 外观表面 | 无划伤、磕碰、锈蚀；非可视面划痕 ≤ 5 mm 且 ≤ 2 处 | 目视，≥ 500 lx，30–50 cm |
| G-APP-02 | 尺寸公差（未注） | 外形 ± 1 mm（< 500 mm）；± 2 mm（≥ 500 mm） | 卷尺 / 卡尺 |
| G-APP-03 | 重量公差（未注） | ± 3 % | 电子秤 / 地磅 |
| G-APP-04 | 标识 | 铭牌信息完整、擦拭 10 次不脱落；仅 SM 标识 | 目视 + 擦拭 |

## 运行 RUN
| 编号 | 条目 | 建议判定 | 方法 / 工具 |
|---|---|---|---|
| G-RUN-01 | 送料 / 动作样本数 | 每通道（料道 / 工位）连续 ≥ 100 次小件、≥ 50 次大件 | 计数 |
| G-RUN-02 | 连续运行 | 小件设备 ≥ 2 h；整机 ≥ 8 h（客户见证可 4 h）；温升 ≤ 20 K | 计时 + 红外测温 |
| G-RUN-03 | 运行噪音 | ≤ 70 dB(A) @ 1 m（整机 ≤ 75 dB(A)） | 声级计 A 计权 |
| G-RUN-04 | 取料 / 插件 / 贴装成功率 | ≥ 99.5 %（样本 ≥ 500 次） | 设备记录 |
