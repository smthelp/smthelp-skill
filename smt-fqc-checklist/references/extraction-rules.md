# 资料解析、提取与归类规则 / Extraction & classification rules

## 1. 资料优先级（冲突时高者优先，但冲突本身要记录）
1. Jason 书面确认（聊天/邮件，记日期）
2. SM 操作手册（PDF，带章节页码）
3. SM 参数表 / 产品页规格表（HTML、彩页）
4. 铭牌、标签照片
5. 视频 / 音频（演示、讲解）
6. 3D 图纸页（结构、零件名称，通常无参数）
7. 通用标准（item-library.md 的 G 编号）——只能作建议值（status S）

同一参数两处数值不同：不选，status T，问题里写出“手册 X / 产品页 Y，以哪个为准？”。
资料自己声明“未给出”（如手册写 does not state electrical ratings）而其他资料有值：用有值的那份，来源写清楚，可 status C。

## 2. 各类资料怎么读
| 类型 | 方法 | 来源写法 |
|---|---|---|
| PDF 手册 | 逐页抽文本；表格页整表抽；无文字层的页转图片（pdftoppm）目视；记录章节号与页码 | `手册 §5.1 p.9` / `Manual §5.1 p.9` |
| 产品页 HTML | 抓“Specifications / 规格”表与 FAQ；忽略营销段落、ROI 计算器、博客 | `产品页 §03 规格表 'Weight'` |
| 彩页 / 参数表 | 同 PDF；图片版用 OCR 或目视 | `彩页 p.2 参数表` |
| 图片 | 看铭牌（电压、功率、频率、序列号格式）、警示标签、接口、包装 | `照片 IMG_0123 铭牌` |
| 视频 | 取字幕或转写；记录出现参数/操作/测试的时间点；关键帧截图 | `视频 'xxx' 01:25` |
| 音频 | 转写；多为营销讲解，只有明确数值才用 | `音频 'xxx' 00:42` |
| 3D 页 | 取零件名称、结构、可动部件，用于结构完整性与装配条目 | `3D 页 'xxx' 零件表` |

每条事实记录：`值 | 单位 | 条件（如“0201 元件时”、“24 V 下”）| 来源 | 原文摘录`。条件不能丢。

## 3. 归类（8 类）→ 检验分区
| 事实类别 | 例子 | 典型落入分区 |
|---|---|---|
| 功能项 | 4 条独立料道、频率/功率旋钮、自动换线 | 功能 / 供料 / 运行 |
| 技术参数 | 电压、功率、CPH、元件范围、料管宽度 | 规格参数核对 |
| 外观要求 | 喷涂、标识、清洁 | 外观与结构 |
| 尺寸公差 | 外形尺寸、重量、行程、间隙 | 外观与结构 / 机构装配 |
| 电气 / 性能指标 | 电流、接地、绝缘、精度、成功率、噪音、温升 | 电气与安全 / 功能运行 |
| 装配与包装 | 安装步骤、紧固、锁定、包装方式 | 机构装配 / 随机文件与包装 |
| 安全与合规 | 安全说明、急停、联锁、警示标识、CE / NR-12 | 电气与安全 |
| 附件备件 | 零件清单、随机工具、备件包、文件 | 结构完整性 / 随机文件 |

## 4. 由事实生成检验项
- 一个可验证的事实 → 一个检验项；一个安装/操作步骤 → 对应一个动作检查（能否按手册完成）。
- 故障排除表：每个“问题”反推一个检验项（例：“指示灯不亮 → 开关/锁定” → 指示灯检查）。
- 零件清单：结构完整性一项总查 + 关键件（连接器、定位销、振动器、电机、传感器）各一项。
- 参数有值无公差 → 标准值填资料值，上下限用 G 编号建议值（status S）或留空问 Jason（status T）。
- 资料完全未提及但该产品线必检（registry.json `must_items`）→ status T，问题写清需要什么。
- 不适用的分区项（如振动飞达无皮带）：保留并写“本机型无 X，判 NA”，来源写依据。

## 5. 不得做的事
- 不把营销数字（节省 %、ROI、“less than one LED lamp”）写进判定标准。
- 不把供应商名称、型号、联系方式写进表格。
- 不从相似机型借参数；不“四舍五入”资料数值；不改单位不注明。
