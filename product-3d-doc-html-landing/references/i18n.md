# 多语言

- 语言清单 = `config.languages`（顺序即菜单顺序，第一个为默认与 x-default）；RTL 语言列入 `rtl_languages`（模板按该列表设置 `dir=rtl`）。
- `?lang=xx` 覆盖；localStorage 键 `<ls_prefix>_lang` / `<ls_prefix>_theme`，每页唯一。
- 运行时只用 `textContent`/`setAttribute` 写入，杜绝 HTML 注入；构建时英文预填，便于 SEO 与无 JS 阅读。

## 翻译子代理提示词（每种语言一个，并行）
```
Translate a JSON file of English landing-page strings into <LANGUAGE> (<code>) for a B2B page about <PRODUCT> by Southern Machinery.
Input: <work>/todo_<code>.json (<N> keys). Output: <work>/out_<code>.json with exactly the same keys, values translated.
Rules: professional <LANGUAGE> for factory managers and engineers. Keep unchanged: all model names (<list>), PCB, SMT, THT, SMEMA,
ESD, PLC, LED, AGV, MES, IoT, units, all numbers exactly, emails, phones, "Southern Machinery". Plain text only: no HTML, markdown or entities.
Never use the words hook, diagnosis, framework, vehicle, loop, CTA, Dan Koe (nor their local equivalents as labels).
Write with Python json.dump(ensure_ascii=False). Verify with Python: same key set, no empty values, no '<'. Report only 'done' and key count.
```
中文追加行业术语表（上板机、下板机、料框、吸板机、接驳台…）与禁用中文词（钩子、诊断、框架、载体、闭环）。

## 复用
`i18n_tools.py reuse <work> <旧页面>/i18n ...`：相同英文串直接复用旧译文（页脚、ROI、通用 UI 通常可复用 70+ 键），只翻新键。
