# Southern Machinery 外贸营销平台矩阵

> 用于 smthelp-content-build 裂变时选择平台形态。频率与格式为通用建议，可按团队人力调整。

| 平台 | 内容形态 | 建议长度 | CTA 偏好 | 最佳角色 |
|------|----------|----------|----------|----------|
| 官网产品页 | 图文 + 参数表 + 视频 | 800–1500 词 | 询盘表单 / WhatsApp | 采购、工艺 |
| Google SEO 文章 | 长文（选型指南、对比、FAQ） | 1200–2000 词 | 下载规格书 / 内链产品页 | 认知阶段客户 |
| LinkedIn | 图文帖 / 短文 | 100–300 词 | 私信 / 评论 / 关注 | 老板、采购、行业人脉 |
| EDM | 邮件 | 150–400 词 | 下载规格书 / 回复询盘 | 已有联系人 |
| YouTube | 演示/讲解视频 | 2–5 分钟 | 评论 / 官网链接 | 工艺、技术决策者 |
| WhatsApp | 短讯 + 图片/视频 | 50–150 词 | 直接对话 | 已建立联系客户 |
| Facebook / X | 短帖 | 80–150 词 | 私信 / 官网链接 | 泛行业关注者 |
| 展会物料 | 一页 A4 | 核心参数 + 二维码 | 扫码看视频 / 加好友 | 现场访客 |

## 各平台语言与语气

- 官网 / SEO / YouTube：专业、技术、事实驱动，英文为主
- LinkedIn：行业洞察 + 轻销售，突出应用场景与算账逻辑
- EDM / WhatsApp：直接、短、明确下一步
- 展会：信息密度高、可视化强（照片、视频二维码）

## 事实合规总原则

任何平台上的任何说法（产能、精度、能耗、交期、认证、客户案例、价格、ROI）都必须来自已验证来源；没有来源就标「待确认 / to be confirmed」，或删除该说法。
