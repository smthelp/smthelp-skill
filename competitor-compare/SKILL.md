# Competitor Compare

## Purpose

Prepare professional competitor comparison material that is useful in sales conversations and avoids unsupported claims.

## Workflow

1. Identify the competitor, machine category, customer use case, and decision criteria.
2. Use Southern Machinery catalog-backed data for Southern Machinery specs.
3. Use only public or user-provided competitor data; label unknown fields as `Need public data confirmation`.
4. Compare objectively: application fit, speed, PCB range, customization, line completeness, ROI logic, service model, spare parts, and value positioning.
5. Avoid negative or defamatory language; position Southern Machinery strengths constructively.

## Default Positioning Angles

- Complete SMT + THT + wave soldering + board handling line support.
- Shenzhen manufacturing and responsive customization.
- Cost-effective automation for high-mix EMS factories.
- ROI-oriented solution design and practical service support.

## Shared Southern Machinery Rules

- Default customer-facing output to English unless the user requests another language.
- Keep emails under 300 words, WhatsApp messages under 100 words, and LinkedIn posts at 150-300 words with 3 relevant hashtags.
- Use consultative selling: identify pain points, use verified data, position Southern Machinery as an automation partner, and end with a clear CTA.
- Do not invent prices, lead times, unavailable specifications, customer names, or unverified competitor claims.
- Treat product specs as catalog-based; if a requested spec is outside known data, say it needs further confirmation via `jasonwu@smthelp.com`.
- Include assumptions for ROI or capacity calculations so the customer can verify them.
- Add the Southern Machinery email signature when drafting a full email.
