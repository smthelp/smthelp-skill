# Unified brand format standard (SM-PPT-202309)

Machine-readable copy: `config/brand.json`. This page explains it.

## Template
- File: `assets/template/southern-machinery-template-202309.pptx`, 16:9 (13.333 x 7.5 in).
- Master provides: Southern Machinery logo (top-left), teal/green swoosh, light circuit background, footer `www.smthelp.com` bottom-right. Never redraw, move or recolour them.
- Content slides use the layout of template slide 2 ("1_标题幻灯片").
- Template slides 5 and 6 (Best After-sales service; Welcome Inquiry) are appended unchanged at the end of every deck; template slides 1-4 are removed.

## Colours
| Role | Hex | Use |
|---|---|---|
| primary | #00A3B4 | headers, table heads, numbers, accents |
| primary_bright | #00C5DA | template swoosh highlight (master only) |
| secondary | #98B341 | Advantages column, metric top bars, checks |
| title | #2F5597 | slide titles (accent1 75%), item heads |
| muted | #6E747A | footers, captions |
| light_green | #E9EFD6 | alternating rows, advantage cards |
| light_teal | #E5F6F8 | feature cards, lead bands |
| ink | #1F1F1F | body text |

## Typography
- One font family: 微软雅黑 (Microsoft YaHei) for Latin and East-Asian runs (qa.py checks every run).
- Title 28 pt bold navy with soft shadow (24/22 pt for long titles); body 13-15 pt; table 10-12.5 pt; minimum 10 pt.

## Layout
- Safe area: x 0.75-11.65 in, y 0.95-6.45 in. Title band x 1.85-9.45 in, y 0.05-0.63 in.
- Cards: rounded rectangles, 1 pt teal outline; FAB = 3 columns (teal Features, green Advantages, navy Benefits).
- Every slide gets speaker notes with sources when facts were reconciled.

## Content identity
- Company line on title slide: "Shenzhen Southern Machinery Sales and Service Co., Ltd. · Product Presentation | <Month Year>".
- Closing value line: one-stop SMT peripheral supply, customization, worldwide after-sales support (7x24 support, free installation/training, 1-day spare-parts lead time, 1-month custom solution - from the template slide).
- No supplier or third-party brand names/logos; customer logos only if the source deck already showed them.

## File names (SEO)
`<Category>-<Model>-<2-4 keywords>-Southern-Machinery.pptx`, English, hyphens, <= 110 chars, generated by `seo_name.py`.
Core properties: title, subject, keywords filled from `spec.meta`; author "Southern Machinery".

## Changing the brand
New template or colours = edit `config/brand.json` (+ replace the template file), run the example, bump **major** if old specs no longer fit, else minor.
