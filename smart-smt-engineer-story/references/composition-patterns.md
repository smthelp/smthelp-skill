# Composition Patterns

Choose one structure per image.

## Manual Bottleneck To Automation

Best for labor-saving posts.

Composition: left side has a small manual bottleneck; engineer connects it to a cleaner automated machine on the right.

## Sample Testing Bench

Best for consultation and inquiry follow-up.

Composition: engineer places a PCB sample into a small test fixture or machine module. Labels can show "PCB", "BOM", "Target Output".

## Line Planning Table

Best for proposal and line-design content.

Composition: engineer arranges machine blocks on a clean table or blueprint. Keep it tactile, not a formal CAD drawing.

## Process Gap Repair

Best for educational posts.

Composition: a conveyor/path has one gap; engineer bridges it with the right automation module.

## Quality Check Moment

Best for AOI, soldering, and consistency.

Composition: engineer watches an AOI lens or inspection light over a PCB. Use few labels.

## Originality Rule

Do not copy original repository character shapes, exact props, or known compositions. Recreate the principle: one clear conceptual action, sparse scene, and a little narrative charm.
