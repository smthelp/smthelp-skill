# Smart-SMT Engineer Story

Create 16:9 English marketing illustrations that preserve the original repository's useful structure: one idea per image, clear visual storytelling, strong whitespace, and a small recurring action figure. Replace the original Xiaohei IP with a neutral Southern Machinery-style simplified engineer/operator.

This version is best for educational posts and sales storytelling: manual bottlenecks, process fixes, sample testing, line planning, and engineering support.

## Read When Needed

- `references/style-dna.md`: engineer-story visual DNA, character rules, and forbidden styles.
- `references/composition-patterns.md`: narrative composition patterns.
- `references/prompt-template.md`: imagegen prompt template.
- `references/qa-checklist.md`: validation and iteration checklist.
- `assets/southern-machinery-logo-300x83.png`: official Southern Machinery logo reference asset. Use this PNG when a logo is needed; do not redraw, approximate, or replace the logo with plain text.

## Workflow

1. Read the user's article, sales point, or campaign goal.
2. Extract the cognitive anchor: bottleneck, before/after, handoff, process gap, technical consultation, sample testing, or automation upgrade.
3. Put the simplified engineer/operator into the core action. The character should repair, guide, align, test, sort, inspect, or move PCB/process elements.
4. Keep the figure neutral and industrial. It is not a mascot, not a copied character, and not the center of the brand.
5. Produce a shot list first when the user asks for multiple concepts. Default to 3 concepts.
6. For generation requests, create one imagegen prompt per image and validate with the QA checklist.

## Shot List Format

```markdown
## Concept 1: [Name]
Placement: [where this image fits]
Core idea: [one sentence]
Engineer action: [what the figure does]
Suggested elements: [3-5 visual elements]
English labels: [0-5 short labels]
Imagegen prompt: [prompt]
```

## Brand Notes

Use English by default. Keep claims conservative and verifiable. Remind the user to review any price, delivery, warranty, custom specification, customer name, or ROI statement before external use.
