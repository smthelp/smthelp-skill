# 英文回复邮件模板

## 规则
- To：主联系人；CC：保留客户方全部抄送人。
- Subject：`RE: <原主题> – Southern Machinery <价值短语>`（如 Standard Platform Overview / Proposal for <application>）。
- 语气：专业、友好、简洁；不过度承诺；所有 Jason 才知道的数字留 [ ]。
- 结构：
  1. 称呼 + 感谢 +（如延误）一句致歉
  2. 一句定位：我们认真看了需求，给出清晰、诚实的适配说明
  3. 标准平台简介（只用公开规格）+ 需要按产品族配置的地方
  4. 按客户的分档/清单逐条回应（推荐、标准功能、选配、不含）
  5. 商务概览：价格区间 [ ]、交期 [ ]、制造地、培训、服务与备件 [ ]
  6. 唯一主行动：用客户样品免费在线演示 + 一页评估报告（周期、质量、ROI）
  7. 索取资料清单（附件、图纸/样品 2–3 个代表件、时间表）
  8. 我方下一步承诺日期 [date]（可选：30 分钟技术通话）
  9. 签名
