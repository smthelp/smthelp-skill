# 输出模板（四节）

开头一句"关键判断"：最重要的匹配结论 + 回复时限。

**性质**：RFI / RFQ / 订单；首发日期；催复次数；我方是否已回复。

## 1. 客户背调
| 项目 | 内容 | 来源 / 可信度 |
（公司、股权、行业、规模、集团营收趋势、发件工厂营收/利润/员工、终端客户）
**判断**：经营状况如何影响本次采购诉求。
**采购规模（推测）**：首单规模、复制潜力、预算窗口。
**决策链**：姓名 – 职位 – 角色（经济决策 / 技术评估 / 发起 / 执行）。
**信息缺口（待确认）**：附件、目标工厂、规格图纸、现有供应商、时间表、预算、合规要求。

## 2. 联系人画像
职权 / 风格 / 痛点 / 关注点 / 潜在异议 / 性格与意向（推测）/ 打法。

## 3. 匹配方案
**关键判断**（含不匹配点）
| 产品 | 公开规格 | 定位 |
**逐条需求对应**（✓ / 部分 / ✗ / 待确认）
**产能分档**（scripts/capacity_calc.py，标"估算"）
**卖点**（≤4 条）**风险**

## 4. 跟进计划
| 阶段 | 时间（北京时间，附客户当地时间） | 目标 | 待确认 |
| ① 首次回复 | 24 小时内；已被催复则当天 | 致歉（如延误）、概览、诚实定位、索取资料 | 价格、交期 |
| ② 资料包 / 报价 | +7 天 | 规格书、配置表、预算价、视频；约技术通话 | 图纸、样品、目标工厂 |
| ③ 样品或在线演示 | +14–21 天 | 用客户样品实机演示，一页评估报告 + ROI | 治具、换型时间、检测能力 |
| ④ 确认与促单 | +30–45 天 | 正式报价、试点 1 台、进入预算短名单 | 决策时间、付款与验收条款 |
无回音规则：7 天后发一封简短跟进，抄送技术评估人，只讲一个价值点。

## 常见异议库（持续补充）
| 异议 | 回应要点 |
|---|---|
| 中国供应商售后慢 | 远程在线支持、备件库存与发货时效（待 Jason 确认数据）、视频培训、可选当地合作伙伴 |
| 是否真的"标准机" | 说明哪些是标准、哪些是按产品族配置的治具；不夸大 |
| 汽车行业案例 | 只提可公开的客户；没有就说明可用样品验证代替 |
| CE / 安全合规 | 待确认后再答，不提前承诺 |
| 价格比欧洲低是否质量差 | 用样品演示数据和评估报告说话 |
