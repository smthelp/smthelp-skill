# 背调数据源与可信度

| 信息 | 首选来源 | 可信度 |
|---|---|---|
| 公司简介、成立年份、工厂、员工 | 官网 Company / Locations 页面 | 高 |
| 集团营收、股权、工厂清单 | 年报 / GRI 或 ESG 可持续报告（PDF，常含 5 年营收与股权结构） | 高 |
| 子公司营收、利润、员工 | 各国工商：罗马尼亚 comercial.ro / atlasfirme.com / listafirme.ro；奥地利 firmenakte.at / firmenmonitor.com；德国 northdata.de / unternehmensregister.de；捷克 rejstrik.penize.cz；墨西哥/美国看新闻与 D&B；印度 Tofler / Zauba | 中高 |
| 新闻、扩产、裁员、新工厂 | 当地财经媒体（如 ZF.ro）、官网 Newsroom、Eurofound | 中 |
| 第三方概况 | Tracxn、ZoomInfo、EMIS、D&B、LinkedIn 公司页 | 中（员工数常不准） |
| 联系人职位 | LinkedIn（搜索"姓名 + 公司"）、XING、FinalScout、RocketReach 摘要 | 中 |
| 终端客户 | 官网案例、维基、新闻、联系人头衔（如"VW Group"） | 中/低 |

## 检索套路（最多 6–8 次）
1. `<公司> revenue employees plants <发件工厂城市>`
2. `<公司> Umsatz / sustainability report / annual report <年份>`（用当地语言）
3. `<子公司法人全称> cifra de afaceri / Umsatz / revenue <年份>`
4. `<公司> "<抄送人姓1>" OR "<姓2>" purchasing engineering`
5. 如需要：`<公司> new plant / investment / automation <年份>`

## 需要推断的内容（一律标"推测"）
- 经营压力（营收下降、亏损、裁员 → 更重视降本和 ROI）
- 预算窗口（Q4 常是下一年资本预算编制期）
- 采购规模（平台评估 → 多台多厂；首单通常 1–2 台试点）
