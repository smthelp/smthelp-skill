# figma-generate-design 安装说明

## Codex / 通用 Agent

把整个 `openai-skills-figma-generate-design` 文件夹复制到 Agent 的 skills 目录，然后在新对话里让 Agent 使用该 Skill。

## Claude / 其他 Agent

如果客户端支持 Skills，把本目录作为一个 Skill 文件夹导入；如果不支持，则让 Agent 直接读取本目录 `SKILL.md` 作为执行规则。

## 最小验证

让 Agent 回答：这个 Skill 的用途是什么、什么时候使用、需要读取哪些附加资源。能准确回答即安装成功。
