# 内容矩阵复用（SMT 外贸）

## 核心定位

写一篇 3000 字技术长文的成本高，只发一个渠道是浪费。但**复用不等于复制粘贴**——每个渠道的读者状态不同，同一份素材必须重新组装，而不是换个标题重发。

核心原则：**素材共用，角度重切**。长文提供事实与参数，各渠道从中各取一段，按自己的逻辑重讲一遍。

---

## 触发场景

- "这篇技术文章帮我拆成社媒和邮件"
- "这个客户案例还能用在哪"
- "把这份产品资料改造成多条内容"
- 内容排期时一次生产一周素材

---

## SM 硬约束

- 每个渠道产物都要满足 `smthelp-brand-voice` 的术语、禁用词与语气要求
- 涉及报价/配置的产物（落地页、报价说明、平台列表）必须带强制 CTA 或注明"配置确认后报价"
- 参数和案例在拆分过程中**不得走样**——拆细最容易发生的错误是把"0.8 s/件"写成"约 1 秒"

---

## 工作流

### Step 1：拆解源素材

把源内容拆成四类原子素材，后续所有渠道都从这四类里取：

| 类型 | 内容 | 用途 |
|---|---|---|
| **事实** | 参数、工况、时间、数量 | 所有渠道的证据 |
| **判断** | 我们的观点与立场 | LinkedIn、开发信的钩子 |
| **场景** | 具体板子、产线、客户处境 | 视频、案例、展会物料 |
| **动作** | 客户下一步能做什么 | 每个渠道的结尾 |

输出一张素材表，标出每条素材最适合哪个渠道。

### Step 2：选择复用地形

不是每个渠道都值得做。按源内容类型选：

| 源内容 | 优先拆成 | 可跳过 |
|---|---|---|
| 技术长文 | LinkedIn ×3、开发信、视频大纲 | 展会物料 |
| 客户案例 | LinkedIn、开发信、平台列表、展会 | 视频（除非有现场素材） |
| 产品资料 | 落地页、平台列表、展会、视频大纲 | LinkedIn（除非有角度） |
| 工艺解析 | 视频大纲、LinkedIn、技术长文 | 平台列表 |

**规则**：一次复用产出 **4–6 个渠道产物**，超过 6 个质量必然下降。

### Step 3：按渠道重切角度

同一个素材，不同渠道要换切入角度——这是复用和复制的分界线：

```
源素材：某汽车电子客户 THT 段改造后，节拍从 45s 降到 28s

LinkedIn 角度：为什么瓶颈总在没人算的那一段
开发信角度：给同类客户算一笔人工账
视频角度：改造前后的现场画面对比
平台列表角度：配置清单 + 适用场景
展会角度：一句话 + 一个数字
内部知识角度：这个案例的选型逻辑，下次遇到同类客户可复用
```

### Step 4：逐个渠道产出

#### LinkedIn 帖子（100–200 词，可出 2–3 条）
- 一条取**判断**，一条取**场景**，一条取**数字**
- 三条之间要有明显差异，不能是同一段话改写三遍
- 无 emoji；参数放评论；结尾是问题不是链接

#### 开发信（80–150 词）
- 取**场景** + 一个**数字**
- 结尾一个低门槛动作
- 不要贴产品目录

#### 视频脚本大纲（30–90 秒）
- 只出大纲，交给 `smthelp-video-script` 展开
- 标明：前 3 秒画面、中段素材、结尾动作
- 需要现场素材的，明确标注"待拍"

#### 平台列表更新（Alibaba / Made-in-China）
- 取**事实**参数，补充属性字段
- 交期写区间，认证按实际

#### 展会话术（1 主标 + 3 卖点）
- 取**数字**做主标
- 每条卖点 ≤ 8 词

#### 内部知识条目
- 取**判断**与选型逻辑
- 格式：什么情况下适用 / 不适用 / 客户常问什么 / 我们怎么答

### Step 5：一致性校验

拆完后逐条核对：

- 参数在所有渠道里完全一致（尤其数字与单位）
- 同一个案例没有在不同渠道里被写成不同的客户描述
- 需要现场素材的产物已标注待拍
- 每个渠道都有明确的下一步动作

## 输出格式

```
【素材表】
事实：[…]
判断：[…]
场景：[…]
动作：[…]

【本次产出清单】
1. LinkedIn A — 角度：[…]（约 X 词）
2. LinkedIn B — 角度：[…]
3. 开发信 — 角度：[…]
4. 视频大纲 — 角度：[…]（待拍素材：…）
5. 展会话术 — 主标：[…]
（按实际选择 4–6 项）

--- 以下逐个展开 ---

### 1. LinkedIn A
[正文]

### 2. …
```

## Gotchas

1. **不要把同一段话改写三遍当成三条 LinkedIn**
   解释：读者会连着看到。三条必须取不同素材（判断 / 场景 / 数字），读起来像三个不同角度的观察。

2. **不要为了凑渠道数量硬拆**
   解释：素材撑不起 6 个渠道就只做 4 个。硬凑的产物会稀释内容质量，也会让账号看起来在刷屏。

3. **不要让参数在拆分中走样**
   解释：`0.8 s/件` 在长文里准确，到社媒变成"不到 1 秒"，到视频口播变成"很快"——这是复用最常见的退化。每个数字逐个核对。

4. **不要跳过需要拍摄的素材标注**
   解释：视频大纲里写了"改造前后画面对比"但没素材，会导致排期卡住。明确标"待拍"并说明拍什么。

5. **不要把内部选型逻辑直接发到公开渠道**
   解释：内部知识条目里可以写"什么情况下我们不划算"，公开渠道要改写为"什么场景更适合其他方案"，不要把话说死。

6. **不要所有渠道用同一个 CTA**
   解释：LinkedIn 用问题引导评论，开发信用发 Gerber，落地页用下载配置清单，展会用扫码看视频。CTA 要匹配读者在该渠道的心理距离。
