# Prompt snippets (reuse in browser/subagent tasks or when drafting)

## Source read
"Read <source> in full. List every numeric spec with unit, the condition it is stated under, and the section/figure it comes from. List anything the document says it does NOT state. Do not infer missing values."

## Theme planning
"Required topics: <list>. Map each to one of 10 video slots (V01–V10, see method.md). Each video makes one point. Give theme ZH/EN, length (15/30/45/60 s), type, audience (role + line type)."

## Shot drafting
"Write shots as 10-field tuples (dur, size ZH/EN, visual ZH/EN, on-screen ZH/EN, VO ZH/EN, source). Shot 1 ≤ 3 s with the machine moving. One number per shot, only from META.facts. VO ≤ 15 words EN. End with OUTRO. Durations add to <N> s."

## Platform copy
"For each video: YouTube Shorts title ≤ 70 chars with head keyword first + #Shorts, 2–3 sentence description, LinkedIn post (problem → method → product → one question) with ZH reference, TikTok one-liner + emoji, 3–5 SEO keywords, 5–8 hashtags. No price, lead time, stock, warranty, ROI %, competitor names."

## FAT rows
"For section <X>, write rows (item ZH/EN, quantified criterion ZH/EN, method ZH/EN, basis M/P/G…). Use documented values first; where none exists use general SMT FAT practice and tag G."

## Self-check before build
"List every number on screen and its source; every claim not in the sources; every ZH line without an EN twin. Fix, then run qa_copy.py."
